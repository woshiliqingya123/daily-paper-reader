## 摘要
大语言模型的最新进展提升了编程智能体的能力，但针对复杂的端到端网站开发的系统性评估仍然有限。为了填补这一空白，我们推出了 Vision2Web，这是一个用于视觉化网站开发的分层基准，涵盖了从静态 UI 到代码生成、交互式多页面前端复现，到长程全栈网站开发的各个阶段。该基准基于真实世界的网站构建，包含 16 个类别的共 193 个任务，拥有 918 张原型图像和 1,255 个测试用例。为了支持灵活、全面且可靠的评估，我们提出了一种基于工作流的智能体验证范式，该范式由两个互补组件组成：一个 GUI 智能体验证器和一个基于视觉语言模型（VLM）的裁判。我们在不同的编程智能体框架下对多个视觉语言模型进行了评估，结果显示在所有任务层级上都存在显著的性能差距，即使是最先进的模型在全栈开发方面仍然面临挑战。

## Abstract
Recent advances in large language models have improved the capabilities of coding agents, yet systematic evaluation of complex, end-to-end website development remains limited. To address this gap, we introduce Vision2Web, a hierarchical benchmark for visual website development, spanning from static UI-to-code generation, interactive multi-page frontend reproduction, to long-horizon full-stack website development. The benchmark is constructed from real-world websites and comprises a total of 193 tasks across 16 categories, with 918 prototype images and 1,255 test cases. To support flexible, thorough and reliable evaluation, we propose workflow-based agent verification paradigm based on two complementary components: a GUI agent verifier and a VLM-based judge. We evaluate multiple visual language models instantiated under different coding-agent frameworks, revealing substantial performance gaps at all task levels, with state-of-the-art models still struggling on full-stack development.

随着大语言模型（LLM）在编程领域的应用，自主编程智能体（Coding Agents）已能处理复杂的软件开发任务。然而，现有的评估基准存在局限：要么仅关注文本层面的局部代码修复（如 SWE-Bench），要么仅限于静态单页面的 UI 复现（如 Design2Code）。**Vision2Web 的核心目标是填补复杂、端到端、视觉驱动的网站开发评估空白**。它通过构建一个从静态页面到全栈系统的分层基准，系统性地衡量智能体在处理视觉原型、多页面逻辑协调及长程全栈开发任务时的综合能力。

#### 2. 方法论
Vision2Web 提出了一个**分层任务框架**和一种**基于工作流的智能体验证范式**：
*   **分层任务设计**：

    *   **Level 2 (交互式前端)**：评估多页面逻辑、导航流和组件组织能力。
    *   **Level 3 (全栈网站)**：评估状态管理、后端集成、数据库操作及端到端系统构建能力。
*   **验证范式 (Workflow-based Agent Verification)**：
    *   **核心思想**：将测试过程形式化为有向依赖图，通过预定义的测试工作流约束智能体的执行，确保评估的可重复性。
    *   **GUI 智能体验证器 (Functional Score, FS)**：使用 GUI 智能体（如 WebVoyager 协议）执行专家设计的动作序列，验证功能正确性（如登录、CRUD 操作）。

#### 7. 优点
*   **分层科学性**：通过解耦不同阶段的任务，能够精准定位智能体在视觉理解、逻辑推理或系统构建上的具体缺陷。
*   **评估创新**：提出的“工作流验证”范式平衡了评估的灵活性（智能体交互）与严谨性（结构化约束），解决了端到端软件评估的难题。
*   **数据真实性**：基于真实世界网站而非合成数据，具有极高的实用参考价值。
