## 摘要
搜索智能体将语言模型（LM）与网络搜索相结合，在回答复杂用户查询方面正变得至关重要。由于昂贵的人工标注或繁琐的前提条件，为涉及多步检索和推理的深度研究任务构建训练数据集仍然具有挑战性。在这项工作中，我们介绍了 ORBIT，这是一个包含 20,000 个推理密集型查询及其简短可验证答案的训练数据集，该数据集是使用一种不依赖付费 API 服务的节俭框架生成的。该模块化框架包含四个阶段：种子创建、问答对生成，以及两个验证阶段（自我验证和外部验证）。ORBIT 涵盖 15 个领域，每个训练对需要 4-5 个推理步骤，并需要通过全网进行外部搜索验证。我们使用 GRPO 算法在 ORBIT 上训练 Qwen3-4B 作为基础模型，并在维基百科问答任务上进行了评估。广泛的实验结果表明，ORBIT-4B 在 4B 参数以下的搜索智能体大语言模型（LLM）中表现优异，证明了合成数据集的实用性。我们的框架、代码和数据集均已开源并公开发布。

## Abstract
Search agents, which integrate language models (LMs) with web search, are becoming crucial for answering complex user queries. Constructing training datasets for deep research tasks, involving multi-step retrieval and reasoning, remains challenging due to expensive human annotation, or cumbersome prerequisites. In this work, we introduce ORBIT, a training dataset with 20K reasoning-intensive queries with short verifiable answers, generated using a frugal framework without relying on paid API services. The modular framework relies on four stages: seed creation, question-answer pair generation, and two stages of verification: self and external. ORBIT spans 15 domains and each training pair requires 4-5 reasoning steps, with external search verification required from the complete web. We train Qwen3-4B as the base model on ORBIT using GRPO and evaluate it on Wikipedia question answering tasks. Extensive experiment results demonstrate that ORBIT-4B achieves strong performance among sub-4B LLMs as search agents, proving the utility of synthetic datasets. Our framework, code and datasets are open-sourced and available publicly.

## 1. 核心问题与整体含义
*   **研究动机**：随着搜索智能体（Search Agents）在处理复杂查询（Deep Search）中的作用日益凸显，训练这些模型需要大量涉及多步检索和推理的高质量数据。
*   **核心痛点**：现有的训练数据集要么过于简单（如单跳检索），要么依赖昂贵的人工标注或付费 API 服务（如 GPT-4、Google Search API），且往往需要复杂的预设条件（如知识图谱构建），限制了其规模化和普及性。
*   **研究目标**：在极低预算（Tight Budget）下，构建一个大规模、高复杂度且可验证的合成数据集，用于提升轻量级搜索智能体的推理能力。

## 2. 方法论：ORBIT 框架
ORBIT 采用了一个四阶段的模块化生成框架，核心思想是利用免费的搜索增强型 LLM 接口进行“生成-验证”循环：
1.  **种子创建 (Seed Creation)**：手动确定 15 个领域（如科技、法律、谜题等），利用工具生成 100 个维基百科类别，并提取相关页面标题作为生成 QA 对的原始种子。
2.  **QA 对生成 (QA Pair Generation)**：使用自动化脚本调用 DeepSeek-V3.1（开启搜索和思考模式），根据种子生成“反向问题”（即描述复杂、答案简短的问题），要求每个问题需 4-5 步推理。
3.  **自我验证 (Self-Verification)**：再次调用 DeepSeek-V3.1 对生成的 QA 对进行自查，要求其提供支撑事实的引用 URL，并由 Qwen3-4B 过滤掉验证不充分的样本。
4.  **外部验证 (External Verification)**：为消除模型自偏见，爬取引用 URL 的网页内容，利用 Qwen3-4B 和 GPT-OSS-120B 作为独立裁判，根据网页原文判断 QA 对的准确性。
*   **训练算法**：使用 **GRPO (Group Relative Policy Optimization)** 强化学习算法，以答案的准确匹配（Exact Match）作为奖励信号，在 Qwen3-4B 基础上进行微调。

*   **性能领先**：ORBIT-4B 在 4B 参数以下的搜索智能体中表现最强，平均 EM 准确率达到 49.1，比 Search-R1-4B 高出 **9.0** 个百分点。

*   **合成数据价值**：证明了即使在没有昂贵 API 的情况下，通过严谨的多级验证框架，合成数据也能产生高质量的监督信号，显著提升小模型的搜索推理能力。
*   **学习曲线**：对于小模型，同时训练简单和复杂任务比仅训练复杂任务更有助于模型收敛。

## 7. 优点
*   **极高性价比**：为资源受限的实验室提供了一套可行的深度搜索数据生成方案。
*   **验证机制严谨**：引入了外部网页爬取和独立模型裁判，有效降低了合成数据中常见的“幻觉”和“自圆其说”问题。
*   **开源贡献**：全套框架、20K 数据集及训练代码均已开源，具有很高的复用价值。

## 8. 不足与局限
*   **生成周期长**：依赖网页自动化脚本导致数据获取速度较慢，难以在短时间内完成百万级数据的生成。

*   **工具链依赖**：框架高度依赖 DeepSeek 等特定模型的网页搜索功能，若相关接口策略调整，框架的稳定性可能受影响。
