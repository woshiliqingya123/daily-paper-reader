## 摘要
深度研究智能体 (DRA) 将大语言模型 (LLM) 的推理能力与外部工具相结合。记忆系统使 DRA 能够利用历史经验，这对于高效推理和自主演化至关重要。现有方法依赖于从记忆中检索相似轨迹来辅助推理，但面临记忆演化效率低下以及存储和检索成本不断增加的关键局限。为解决这些问题，我们提出了一种新型的记忆智能体 (MIA) 框架，该框架由“管理者-规划者-执行者” (Manager-Planner-Executor) 架构组成。记忆管理者是一个非参数化记忆系统，可以存储压缩后的历史搜索轨迹。规划者是一个参数化记忆智能体，能够为问题生成搜索计划。执行者是另一个在搜索计划指导下进行信息搜索和分析的智能体。为了构建 MIA 框架，我们首先采用交替强化学习范式来增强规划者与执行者之间的协作。此外，我们使规划者能够在测试时学习过程中持续演化，在不中断推理过程的情况下，随推理同步进行实时更新。此外，我们在参数化记忆和非参数化记忆之间建立了双向转换循环，以实现高效的记忆演化。最后，我们引入了反思和无监督判断机制，以提升在开放世界中的推理和自我演化能力。在 11 个基准测试上的广泛实验证明了 MIA 的优越性。

## Abstract
Deep research agents (DRAs) integrate LLM reasoning with external tools. Memory systems enable DRAs to leverage historical experiences, which are essential for efficient reasoning and autonomous evolution. Existing methods rely on retrieving similar trajectories from memory to aid reasoning, while suffering from key limitations of ineffective memory evolution and increasing storage and retrieval costs. To address these problems, we propose a novel Memory Intelligence Agent (MIA) framework, consisting of a Manager-Planner-Executor architecture. Memory Manager is a non-parametric memory system that can store compressed historical search trajectories. Planner is a parametric memory agent that can produce search plans for questions. Executor is another agent that can search and analyze information guided by the search plan. To build the MIA framework, we first adopt an alternating reinforcement learning paradigm to enhance cooperation between the Planner and the Executor. Furthermore, we enable the Planner to continuously evolve during test-time learning, with updates performed on-the-fly alongside inference without interrupting the reasoning process. Additionally, we establish a bidirectional conversion loop between parametric and non-parametric memories to achieve efficient memory evolution. Finally, we incorporate a reflection and an unsupervised judgment mechanisms to boost reasoning and self-evolution in the open world. Extensive experiments across eleven benchmarks demonstrate the superiority of MIA.

### 论文总结：Memory Intelligence Agent (MIA)

#### 1. 核心问题与整体含义
论文针对**深度研究智能体 (Deep Research Agents, DRAs)** 在处理复杂、多步任务时记忆系统的局限性进行了研究。
*   **研究动机**：现有的智能体记忆系统多依赖于“长上下文记忆”，即直接检索并堆叠历史搜索轨迹。这种方式存在四大痛点：1) 上下文过长导致注意力稀释；2) 引入无关噪声降低推理能力；3) 存储与检索成本随时间激增；4) 仅存储“事实性知识”而忽略了“过程性经验”（即如何获得结果的策略）。
*   **核心目标**：构建一个能够高效存储、检索并能通过历史经验实现“自我演化”的记忆框架，使智能体不再每次从零开始搜索。

#### 2. 方法论
MIA 提出了一个**管理者-规划者-执行者 (Manager-Planner-Executor)** 的三层架构：
*   **核心思想**：将记忆分为**非参数化记忆**（显式存储压缩后的工作流）和**参数化记忆**（通过训练将经验内化到模型权重中），并实现两者的双向转换。
*   **关键技术细节**：
    *   **记忆管理者 (Manager)**：负责非参数化记忆。它将冗长的搜索轨迹压缩为结构化的“工作流摘要”，并根据语义相似度、价值奖励和频率奖励进行混合检索。
    *   **规划者 (Planner)**：作为认知中枢，利用检索到的记忆生成分步搜索计划，并具备“反思-重规划”能力。
    *   **执行者 (Executor)**：负责具体操作，根据计划调用外部工具（如搜索引擎、图像搜索）并反馈结果。
*   **算法流程**：
    1.  **两阶段交替强化学习 (RL)**：使用 **GRPO (Group Relative Policy Optimization)** 算法。第一阶段训练执行者理解并遵循计划；第二阶段训练规划者吸收记忆并优化规划策略。
    2.  **测试时学习 (Test-Time Learning, TTL)**：在推理过程中实时更新规划者的参数，实现边推理边进化。
    3.  **无监督自我演化**：引入类似学术评审的“审稿人-领域主席 (Reviewer-AC)”机制，在没有标准答案的情况下，通过逻辑、事实和格式三个维度自主判断轨迹质量，驱动模型进化。

#### 3. 实验设计
*   **数据集/场景**：涵盖了 11 个基准测试，分为多模态和纯文本两类。
    *   **多模态**：FVQA, InfoSeek, SimpleVQA, LiveVQA, MMSearch, 以及两个内部数据集 (In-house 1/2)。
    *   **纯文本**：HotpotQA, 2WikiMultiHopQA, SimpleQA, GAIA。

    *   **开源系列**：Qwen2.5-VL (7B/32B)。
    *   **记忆框架**：RAG, Mem0, A-Mem, ExpeL, Memento 等。

#### 4. 资源与算力
*   **算力设备**：实验使用了 **8 张 GPU**（具体型号未标明，但提到基于 veRL 框架进行分布式训练）。
*   **模型配置**：执行者初始化为 Qwen2.5-VL-7B，规划者初始化为 Qwen3-8B，管理者/评判者使用 Qwen3-32B。
*   **训练细节**：执行者训练 8 个 epoch，规划者训练 4 个 epoch，学习率均为 $1 \times 10^{-6}$。

#### 5. 实验数量与充分性
*   **实验规模**：论文在 11 个数据集上进行了大规模测试，并针对不同规模的 Executor（从 7B 到 GPT-5.4 级别）进行了泛化性验证。
*   **消融实验**：详细对比了“仅记忆”、“仅规划”、“加入反思”、“加入训练”以及“加入 TTL”的效果，验证了各模块的贡献。
*   **客观性**：通过工具调用分布分析、响应长度演化分析以及无监督与有监督效果对比，多维度展示了 MIA 的性能，实验设计较为严谨、客观。

#### 6 主要结论与发现
*   **性能飞跃**：MIA 显著提升了现有 SOTA 模型的表现。例如，将 GPT-5.4 在 LiveVQA 上的表现提升了 9%。
*   **以小博大**：搭载 MIA 框架的 **Qwen2.5-VL-7B** 在平均性能上超过了未搭载该框架的 **Qwen2.5-VL-32B** 约 18%。
*   **持续进化**：TTL 机制使模型在处理同一数据集的多次迭代中，准确率稳步上升（如从 59.6% 提升至 61.7%）。
*   **记忆效率**：相比长上下文记忆，MIA 的压缩工作流记忆能更有效地指导多轮工具交互，减少了噪声干扰。

#### 7. 优点
*   **架构创新**：解耦了规划与执行，通过参数化与非参数化记忆的结合，解决了记忆爆炸和检索效率问题。
*   **实时演化**：TTL 机制允许模型在推理阶段“边做边学”，无需中断服务进行离线微调。
*   **无监督能力**：提出的“类审稿人”判断机制为开放世界下缺乏标签的自我进化提供了可行路径。
*   **通用性强**：实验证明该框架不仅适用于开源模型，也能显著增强闭源商业模型的能力。

#### 8. 不足与局限
*   **计算开销**：虽然减少了存储成本，但 TTL 过程中的实时参数更新和多路采样 (Rollout) 会增加推理时的计算延迟和算力消耗。
*   **系统复杂性**：Manager-Planner-Executor 的三层架构涉及多个模型的协同，系统部署和维护的复杂度较高。
*   **工具依赖**：实验主要集中在搜索类任务，对于需要极高实时操作精度或物理交互的智能体场景，其适用性尚待验证。
*   **偏差风险**：无监督判断机制虽然创新，但仍可能受到基础模型（如作为评判者的 Qwen3-32B）本身偏见或幻觉的影响。
