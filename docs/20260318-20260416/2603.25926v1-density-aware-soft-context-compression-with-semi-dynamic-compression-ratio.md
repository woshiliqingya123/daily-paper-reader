## 摘要
软上下文压缩通过将长上下文编码为较少数量的潜标记（latent tokens），从而减少大语言模型（LLMs）处理长上下文的计算工作量。然而，现有框架通常采用统一的压缩率，未能考虑到自然语言信息密度的极大差异。虽然采用密度感知的动态压缩率看似直观，但实证研究表明，模型在处理由输入相关的连续结构超参数参数化的操作时存在内在困难。为了解决这一缺陷，我们引入了半动态上下文压缩（Semi-Dynamic Context Compression）框架。我们的方法包含一个离散比例选择器（Discrete Ratio Selector），它根据内在信息密度预测压缩目标，并将其量化为一组预定义的离散压缩率。该选择器与压缩器在合成数据上进行高效的联合训练，并以摘要长度作为代理来生成压缩率预测的标签。广泛的评估证实，我们以均值池化（mean pooling）为骨干的密度感知框架始终优于静态基准，为上下文压缩技术建立了稳健的帕累托前沿（Pareto frontier）。我们的代码、数据和模型权重可在 https://github.com/yuyijiong/semi-dynamic-context-compress 获取。

## Abstract
Soft context compression reduces the computational workload of processing long contexts in LLMs by encoding long context into a smaller number of latent tokens. However, existing frameworks apply uniform compression ratios, failing to account for the extreme variance in natural language information density. While adopting a density-aware dynamic compression ratio seems intuitive, empirical investigations reveal that models struggle intrinsically with operations parameterized by input dependent, continuous structural hyperparameters. To resolve this pitfall, we introduce Semi-Dynamic Context Compression framework. Our approach features a Discrete Ratio Selector, which predicts a compression target based on intrinsic information density and quantizes it to a predefined set of discrete compression ratios. It is efficiently jointly trained with the compressor on synthetic data, with the summary lengths as a proxy to create labels for compression ratio prediction. Extensive evaluations confirm that our density-aware framework, utilizing mean pooling as the backbone, consistently outperforms static baselines, establishing a robust Pareto frontier for context compression techniques. Our code, data and model weights are available at https://github.com/yuyijiong/semi-dynamic-context-compress

### 1. 核心问题与研究动机
*   **研究背景**：处理长上下文会导致巨大的计算和内存开销（KV Cache 瓶颈）。“软压缩”技术通过将长文本编码为少量的连续潜标记（latent tokens）来缓解这一问题。
*   **核心问题**：
    1.  **固定压缩率的局限性**：现有方法通常对所有文本采用统一的压缩率，但自然语言的信息密度差异巨大（如技术报告与闲聊记录），固定比例会导致信息丢失或计算浪费。
    2.  **连续超参数陷阱**：虽然动态压缩直观上可行，但实验发现 LLM 难以处理由输入决定的、连续变化的结构超参数（如动态生成的标记数量或池化步长），这会导致模型性能崩溃。

### 2. 核心方法论
*   **半动态压缩框架**：核心思想是“预测连续密度，执行离散操作”。
*   **离散比例选择器 (DRS)**：
    *   模型首先通过一个回归头预测文本的连续信息密度 $\hat{y}$（在对数空间）。
    *   引入用户可控的 `scale` 参数，允许用户在推理时手动调节全局压缩的激进程度（偏向质量或偏向效率）。
    *   将连续预测值**量化**为预定义的离散压缩率集合（如 $\{2\times, 4\times, 8\times, 16\times, 32\times\}$）。
*   **骨干结构 (Backbone)**：研究发现**均值池化 (Mean-pooling)** 在无需大规模预训练的情况下，性能显著优于主流的“压缩标记 (Compression Tokens)”方法。
*   **单阶段训练与数据合成**：
    *   **密度代理标签**：利用教师模型生成“极简摘要”，以摘要长度作为信息密度的代理标签进行监督学习。
    *   **联合训练**：在单次编码过程中同时完成密度预测和上下文压缩，使用纯 SFT（监督微调）模式，避免了复杂的强化学习或昂贵的文本重构预训练。

### 6. 主要结论与发现
*   **克服陷阱**：证实了 LLM 无法处理无限变化的连续结构参数，而离散化量化（半动态）能有效保持模型稳定性。
*   **性能领先**：在相同的平均压缩率下，半动态框架的准确率始终优于静态基准，成功建立了更优的帕累托前沿。
*   **结构优劣**：均值池化是软压缩的最优骨干结构；双向注意力在极高压缩倍率（$\ge 16\times$）下对提取关键特征至关重要。
*   **动态增益**：性能提升的幅度与模型选择压缩率的方差成正比，证明了收益确实源于对文本多样性的自适应。

### 7. 优点
*   **创新性地解决了训练难题**：通过离散化手段解决了动态结构参数难以收敛的问题。
*   **用户可控性**：通过简单的 `scale` 参数实现了推理时的灵活调节，无需重新训练。
*   **高效简洁**：单阶段 SFT 流程比传统的“预训练+微调”或“强化学习”方案更易于落地和复现。

### 8. 不足与局限
*   **上下文长度限制**：实验中的训练上下文长度主要在 128 到 1300 标记之间，对于数万甚至数十万标记的“极长”上下文表现尚待验证。
*   **合成数据依赖**：模型性能高度依赖于教师模型生成摘要的质量，可能存在合成数据的分布偏差。
*   **任务局限**：主要集中在问答和摘要任务，对于需要极高精确度（如代码执行、数学证明）的任务，软压缩带来的信息损失风险可能更高。
