## 摘要
KV 缓存压缩对于高效的长上下文大语言模型（LLM）推理至关重要。减少每对（pair）占用空间的方法（如量化和低秩分解）与减少缓存序列长度的方法是正交的。在序列长度维度上，现有方法涵盖了从纯逐出（eviction，即选择保留哪些 KV 对）到合并（merging，即把相似的对组合成更少的对）的范围。这两类方法都受限于原始的缓存条目。我们提出了 KVSculpt，它走向了这一频谱的另一端：不再是选择或组合原始对，而是在连续嵌入空间中优化一组更小的、不受约束的 KV 对，以保留每一层的注意力行为。Key 通过 L-BFGS 进行优化，Value 则通过最小二乘法（least squares）求得闭式解，每隔几步交替进行。在此基础上，我们引入了自适应预算分配，利用低成本的初步（pilot）压缩运行，根据每个组件的难度在各层和 KV 头之间重新分配压缩预算。在具有 2048 个 token 上下文的 Qwen2.5-1.5B-Instruct 模型上，在压缩率 r 为 {0.3, 0.5, 0.7} 的情况下，与 Select+Fit（基于注意力分数的逐出配合最小二乘 Value 拟合）相比，KVSculpt 将 KL 散度降低了 3.5-4.1 倍。自适应分配在不增加额外推理成本的情况下，使 KL 散度进一步降低了 1.3 倍。分析表明，压缩难度高度不均匀：各层初步均方误差（MSE）的差异最高可达 100 倍，而同一层内的两个 KV 头之间的差异最高可达 467 倍，这证明了细粒度的预算分配至关重要。

## Abstract
KV cache compression is critical for efficient long-context LLM inference. Approaches that reduce the per-pair footprint -- quantization and low-rank decomposition -- are orthogonal to those that reduce the sequence length of the cache. Along the sequence-length dimension, existing methods range from pure eviction -- selecting which KV pairs to keep -- to merging, which combines similar pairs into fewer ones. Both remain anchored to the original cache entries. We propose KVSculpt, which moves to the other end of this spectrum: instead of selecting or combining original pairs, we optimize a smaller set of unconstrained KV pairs in continuous embedding space to preserve each layer's attention behavior. Keys are optimized via L-BFGS and values are solved in closed form via least squares, alternating every few steps. On top of this, we introduce adaptive budget allocation, which uses a cheap pilot compression run to redistribute the compression budget across layers and KV heads based on per-component difficulty. On Qwen2.5-1.5B-Instruct with 2048-token contexts, KVSculpt reduces KL divergence by 3.5-4.1x compared to Select+Fit -- attention-score eviction with least-squares value fitting -- across compression ratios r in {0.3, 0.5, 0.7}. Adaptive allocation provides an additional 1.3x KL reduction at no extra inference cost. Analysis reveals that compression difficulty is highly non-uniform: per-layer pilot MSE varies by up to 100x across layers, and the two KV heads within a single layer can differ by up to 467x -- demonstrating that fine-grained budget allocation is essential.

### 1. 核心问题与整体含义（研究动机和背景）
在长文本大语言模型（LLM）推理中，KV 缓存（KV Cache）随序列长度增长而急剧膨胀，成为内存瓶颈。现有的减少序列长度的方法主要分为**逐出（Eviction）**（选择性保留）和**合并（Merging）**（组合相似项）。
*   **研究动机**：作者认为现有方法受限于“原始缓存条目”的离散框架。由于旋转位置编码（RoPE）已将位置信息嵌入向量，KV 对在连续空间中并无固定顺序。
*   **核心思想**：将 KV 缓存压缩重新定义为一个**蒸馏问题**。不再是从原始缓存中“挑选”，而是在连续的嵌入空间中“雕刻”（Sculpt）出一组全新的、不受约束的 KV 对，使其能够最大限度地还原原始的注意力行为。

### 2. 方法论
KVSculpt 的核心流程包括优化算法、查询构造和预算分配：
*   **核心算法（交替优化）**：
    *   **Key 优化**：使用 **L-BFGS**（拟牛顿法）在连续空间中优化 Key 向量。相比 Adam 等一阶优化器，L-BFGS 能更好地处理 Softmax 带来的非凸、陡峭的损失景观。
    *   **Value 求解**：在 Key 固定时，利用注意力权重的线性特性，通过**岭回归（Ridge Regression）**求得 Value 向量的闭式解（最小二乘法）。
*   **损失函数**：结合了输出均方误差（Output MSE）和对数总和指数（Log-Sum-Exp, LSE）匹配项，确保压缩后的缓存不仅输出一致，且注意力质量分布也与原版接近。
*   **合成查询构造**：为了让压缩后的 KV 对能泛化到未来的生成步骤，作者提取上下文中的内容向量（De-RoPE），并应用未来位置的 RoPE 编码来构造“合成未来查询”。
*   **自适应预算分配**：通过一个短促的“试点运行”（Pilot Run）测量各层和各 KV 头的压缩难度（MSE），将固定的总预算动态分配给难度更高的组件（使用平方根平滑处理）。

### 3. 实验设计
*   **模型与数据**：使用 **Qwen2.5-1.5B-Instruct**。测试数据来自 **PG19** 数据集，上下文长度为 2048 token，评估后续 128 token 的生成质量。
*   **对比基准（Baselines）**：
    1.  **Random**：随机保留。
    2.  **Attention Score**：基于注意力分数累积的逐出（类似 H2O）。
    3.  **Select+Fit**：先按分数筛选，再用最小二乘法拟合 Value（目前最强的逐出变体）。
    4.  **Joint Optimization**：使用硬混凝土松弛（Hard Concrete）学习离散掩码的优化方法。
*   **评估指标**：KL 散度（衡量压缩模型与原始模型输出分布的差异）。

### 4. 资源与算力
*   **硬件**：实验在单张 **NVIDIA A100 GPU** 上完成。
*   **耗时**：对于 2048 token 的上下文，在 100 步 L-BFGS 优化下，每层压缩耗时约 **170 秒**。
*   **算力特性**：该方法属于离线/摊销（Amortized）设置，即压缩一次后可供多次查询使用。

### 5. 实验数量与充分性
*   **实验规模**：主实验涵盖了 20 个序列，详细分析和消融实验针对 5 个代表性序列展开。
*   **充分性**：实验覆盖了多种压缩率（0.1 到 0.7）、不同的优化器对比（Adam vs. L-BFGS）、多种查询采样策略以及细粒度的层/头预算分配方案。
*   **客观性**：作者不仅展示了平均性能，还深入分析了“简单”与“困难”序列的差异，并探讨了误差随层数累积的现象，实验设计较为严谨。

### 6. 主要结论与发现
*   **性能飞跃**：在相同压缩率下，KVSculpt 的 KL 散度比最强的逐出基准（Select+Fit）低 **3.5–4.1 倍**。
*   **连续空间的优势**：实验证明，允许 Key 在连续空间自由移动（而非限制在原始位置）是性能提升的关键。
*   **非均匀难度**：不同层之间的压缩难度差异可达 100 倍，同一层内不同 KV 头的难度差异甚至高达 467 倍。
*   **自适应分配有效性**：引入基于试点信号的自适应分配后，KL 散度进一步降低了 1.3 倍，且不增加推理负担。
*   **瓶颈识别**：单层优化已接近极限（达到 Oracle 性能的 92%-98%），未来的瓶颈在于跨层的误差累积。

### 7. 优点
*   **范式创新**：打破了“KV 缓存必须是原始 token 子集”的思维定式，利用连续空间优化提升了信息密度。
*   **高精度**：在 0.3 的压缩率下实现了接近无损（KL < 0.01）的压缩效果。
*   **细粒度控制**：自适应预算分配深入到 KV 头级别，充分利用了模型内部的结构不对称性。

### 8. 不足与局限
*   **压缩成本高**：170 秒的压缩时间意味着该方法不适用于单次、实时的在线推理，更适合系统提示词（System Prompts）或长期存储的文档。
*   **模型规模有限**：实验仅在 1.5B 模型上进行，尚未在大规模模型（如 70B+）或更长上下文（如 128K）上验证。
*   **评估维度单一**：主要依赖 KL 散度，缺乏下游任务（如 MMLU、摘要生成）的直接准确率评测。
*   **层间依赖**：目前的优化是逐层进行的，忽略了层与层之间的级联效应。
