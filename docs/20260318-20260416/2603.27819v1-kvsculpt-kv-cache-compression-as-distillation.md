## 摘要
KV 缓存压缩对于高效的长上下文大语言模型（LLM）推理至关重要。减少每对（pair）占用空间的方法（如量化和低秩分解）与减少缓存序列长度的方法是正交的。在序列长度维度上，现有方法涵盖了从纯粹的剔除（eviction，即选择保留哪些 KV 对）到合并（merging，即将相似的 KV 对组合成更少的对）。这两类方法都受限于原始的缓存条目。我们提出了 KVSculpt，它走向了这一频谱的另一端：不再是选择或组合原始 KV 对，而是在连续嵌入空间中优化一组更小的、不受约束的 KV 对，以保持每一层的注意力行为。键（Keys）通过 L-BFGS 进行优化，值（Values）则通过最小二乘法以闭式解形式求解，每隔几步交替进行。在此基础上，我们引入了自适应预算分配，利用低成本的初步压缩运行，根据每个组件的压缩难度在各层和 KV 头之间重新分配压缩预算。在具有 2048 个 token 上下文的 Qwen2.5-1.5B-Instruct 模型上，在压缩率 r 为 {0.3, 0.5, 0.7} 的情况下，与 Select+Fit（基于注意力分数的剔除结合最小二乘值拟合）相比，KVSculpt 将 KL 散度降低了 3.5-4.1 倍。自适应分配在不增加额外推理成本的情况下，使 KL 散度进一步降低了 1.3 倍。分析表明，压缩难度具有高度的不均匀性：各层之间的初步均方误差（MSE）差异可达 100 倍，而单层内的两个 KV 头之间的差异甚至可达 467 倍，这证明了细粒度的预算分配是必不可少的。

## Abstract
KV cache compression is critical for efficient long-context LLM inference. Approaches that reduce the per-pair footprint -- quantization and low-rank decomposition -- are orthogonal to those that reduce the sequence length of the cache. Along the sequence-length dimension, existing methods range from pure eviction -- selecting which KV pairs to keep -- to merging, which combines similar pairs into fewer ones. Both remain anchored to the original cache entries. We propose KVSculpt, which moves to the other end of this spectrum: instead of selecting or combining original pairs, we optimize a smaller set of unconstrained KV pairs in continuous embedding space to preserve each layer's attention behavior. Keys are optimized via L-BFGS and values are solved in closed form via least squares, alternating every few steps. On top of this, we introduce adaptive budget allocation, which uses a cheap pilot compression run to redistribute the compression budget across layers and KV heads based on per-component difficulty. On Qwen2.5-1.5B-Instruct with 2048-token contexts, KVSculpt reduces KL divergence by 3.5-4.1x compared to Select+Fit -- attention-score eviction with least-squares value fitting -- across compression ratios r in {0.3, 0.5, 0.7}. Adaptive allocation provides an additional 1.3x KL reduction at no extra inference cost. Analysis reveals that compression difficulty is highly non-uniform: per-layer pilot MSE varies by up to 100x across layers, and the two KV heads within a single layer can differ by up to 467x -- demonstrating that fine-grained budget allocation is essential.

### 1. 核心问题与研究动机
*   **核心问题**：长上下文大语言模型（LLM）推理时，KV Cache（键值缓存）会消耗巨大的显存。现有的减少序列长度的方法（如“剔除”或“合并”）都局限于原始缓存条目的离散子集或加权组合。
*   **研究动机**：作者认为这种离散选择框架过于受限。由于位置信息已通过 RoPE 编码嵌入到向量中，压缩后的 KV 缓存不一定非要是原始 token 的子集。通过在连续嵌入空间中直接优化 KV 对，可以更精确地模拟原始注意力的行为，从而实现更高的压缩保真度。

### 2. 方法论
KVSculpt 将 KV 缓存压缩重新定义为一个**蒸馏问题**，核心思想是优化一组全新的、不受约束的虚拟 KV 对。
*   **核心思想**：给定 $N$ 个原始 KV 对，优化 $k$ 个（$k < N$）连续空间中的 KV 对，使压缩后的注意力输出与原始输出之间的差异最小化。
*   **损失函数**：包含两部分：
    1.  **输出 MSE**：匹配注意力机制产生的加权值输出。
    2.  **LSE 匹配**：匹配 Log-Sum-Exp（注意力分数的对数总和），确保在后续与新生成的 token 合并时，注意力权重的分配比例正确。
*   **优化算法**：
    *   **Keys 优化**：使用 **L-BFGS** 算法。由于 Softmax 景观是非凸且陡峭的，一阶优化器（如 Adam）容易陷入局部最优，而 L-BFGS 利用二阶曲率信息能更有效地导航。
    *   **Values 求解**：在 Keys 固定时，Values 的最优解可以通过**岭回归（最小二乘法）**以闭式解形式快速求得。两者每隔几步交替进行。
*   **自适应预算分配**：引入“试点运行（Pilot Run）”机制。先进行简短的统一压缩，测量各层和各 KV 头的 MSE（压缩难度），然后根据难度（使用平方根平滑处理）动态分配压缩预算。

### 3. 实验设计
*   **模型与数据**：使用 **Qwen2.5-1.5B-Instruct**。测试数据来自 **PG19** 测试集，上下文长度设为 2048 token，评估后续 128 token 的生成质量。
*   **Benchmark 与对比方法**：
    *   **Random**：随机保留。
    *   **Attention Score**：基于累积注意力分数剔除（类似 H2O）。
    *   **Select+Fit**：先按分数筛选，再用最小二乘法拟合 Values（目前最强的剔除类基准）。
    *   **Joint Optimization**：使用硬混凝土松弛（Hard Concrete）学习离散门控，是 KVSculpt 的离散对应版本。
*   **评估指标**：使用 **KL 散度**（衡量压缩模型与原始模型输出概率分布的差异）。

### 4. 资源与算力
*   **硬件**：实验使用了 **NVIDIA A100 GPU**。
*   **耗时**：对于 2048 token 的上下文，在单张 A100 上完成 100 步 L-BFGS 优化的压缩过程大约需要 **170 秒**。
*   **适用场景**：由于压缩耗时较长，该方法目前适用于**离线/摊销场景**（如系统提示词、长期引用的文档等），而非单次实时对话。

### 5. 实验数量与充分性
*   **实验规模**：主实验涵盖了 20 个序列，详细分析和消融实验使用了 5 个序列的子集。
*   **充分性**：
    *   测试了多种压缩率（$r \in \{0.1, 0.3, 0.5, 0.7\}$）。
    *   进行了详尽的消融实验，包括优化器对比（L-BFGS vs Adam）、查询向量构造策略、自适应分配的平滑因子等。
    *   **客观性**：对比了包括离散优化在内的多种强基准，实验设计较为公平，且通过 Oracle 实验证明了其单层优化已接近理论极限。

### 6. 主要结论与发现
*   **性能飞跃**：在相同压缩率下，KVSculpt 的 KL 散度比最强的剔除基准（Select+Fit）降低了 **3.5–4.1 倍**。
*   **自适应分配的价值**：通过跨层和跨头的预算重新分配，在不增加推理成本的前提下，使 KL 散度进一步降低了 **1.3 倍**。
*   **压缩难度的非均匀性**：发现不同层之间的压缩难度差异可达 100 倍，同一层内不同 KV 头的难度差异甚至高达 467 倍。
*   **瓶颈所在**：单层优化已接近完美（与 Oracle 仅差 2-8%），但误差会随层数加深而累积（跨层误差放大可达 2-3 个数量级），这是未来改进的方向。

### 7. 优点
*   **打破限制**：首次将 KV 压缩从“离散选择”推向“连续蒸馏”，极大扩展了优化空间。
*   **数学严谨**：结合了 L-BFGS 的非凸优化能力和最小二乘法的解析效率。
*   **细粒度分配**：自适应预算分配机制充分利用了模型内部结构的异质性。

### 8. 不足与局限
*   **计算开销**：压缩过程（优化阶段）计算量大，无法满足实时流式推理的需求。
*   **模型覆盖**：主要在 Qwen2.5-1.5B 上验证，尚未在更大规模（如 70B+）或其他架构（如 Llama 3）上广泛测试。
*   **评估维度**：主要依赖 KL 散度，缺乏下游任务（如 MMLU、摘要生成）的直接准确率评测。
*   **跨层累积误差**：目前的逐层优化策略没有考虑误差在层间的级联效应。
