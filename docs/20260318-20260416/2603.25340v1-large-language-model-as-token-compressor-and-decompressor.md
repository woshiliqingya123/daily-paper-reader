## 摘要
在本文中，我们提出了一个新颖的见解：现成的大语言模型（LLM）可以作为一个优秀的 Token 压缩器和解压器。为了证明这一点，我们设计了一个自表达自编码学习框架，通过微调预训练 LLM，将长文本转换为由离散、变长潜码（称为 Z-tokens）组成的紧凑内部语言，并能从中精确重建原始文本。所得表示具有内容自适应性：通过轻量级的基于 LoRA 的适配器头，语义密集的片段会分配到更多 Z-tokens，而冗余或可预测的区域则会被大幅压缩。实验表明，我们的方法在 Wikipedia、CNN/DailyMail、HotpotQA 和 Qulac 风格的长查询数据集上实现了高达 18 倍的 Token 缩减，同时保持了重建保真度和下游任务性能。这种简单而有效的设计支持包括提示词压缩和直接在 Z-token 空间进行自回归生成在内的多种应用，为实现 Token 高效的长上下文推理提供了一条潜在路径。

## Abstract
In this paper, we establish the novel insight that an off-the-shelf LLM can function as an excellent token compressor and decompressor. To demonstrate, we design a self-expressive autoencoding learning framework fine-tunes a pretrained LLM to translate long texts into a compact internal language of discrete, variable-length latent codes, termed Z-tokens, and to reconstruct the original text exactly from them. The resulting representation is content-adaptive: semantically dense segments receive more Z-tokens, while redundant or predictable regions are aggressively compressed, via lightweight LoRA-based adapter heads. Empirically, our method achieves up to 18 times token reduction on Wikipedia, CNN/DailyMail, HotpotQA, and Qulac-style long-query datasets, while preserving reconstruction fidelity and downstream performance. This simple yet effective design supports applications including prompt compression and autoregressive generation directly in the Z-token space, offering a potential pathway toward token-efficient long-context reasoning.

### 论文总结：大语言模型作为 Token 压缩器与解压器

#### 1. 核心问题与整体含义（研究动机和背景）
大语言模型（LLM）在处理长上下文时面临核心瓶颈：注意力机制的计算复杂度随序列长度呈二次方增长（$O(N^2)$）。现有的 Token 压缩技术主要分为两类：
*   **启发式方法**（如 Token 合并或剪枝）：虽然简单，但容易丢失难以恢复的语义或语用信息。
*   **学习型方法**（如 ICAE、AutoCompressor）：通常生成固定长度的连续向量（Embedding），缺乏透明度、不可解释，且无法根据信息密度动态调整压缩率。

本研究提出，LLM 本身就是强大的语义抽象引擎。论文旨在利用预训练 LLM 的语义知识，将其转化为一个**自表达的自编码器**，将长文本压缩为离散的、变长的内部语言（**Z-tokens**），并能实现精确还原或直接基于该内部语言进行推理。

#### 2. 核心方法论
论文提出了一个基于 LoRA 的自编码学习框架，包含三个核心组件：
*   **LLM 压缩器（Compressor）**：
    *   **核心思想**：将输入序列 $X$ 映射为变长的离散 Z-tokens。
    *   **技术细节**：扩展原有的词表，增加专门的 Z-vocabulary。采用**自回归生成**方式产生 Z-tokens，允许模型根据内容复杂度动态分配 Token 数量。
    *   **离散化处理**：训练时使用 **Gumbel-Softmax** 采样和 **直通估计器（Pass-through Estimator）**，确保梯度可导的同时保持推理时的离散性。
    *   **滑动窗口**：支持超长文本的分段压缩，并通过重叠区域的一致性约束（Cosine Similarity）保证语义连贯。
*   **LLM 解压器（Decompressor）**：
    *   **两种模式**：
        1.  **作为推理器（Inferencer）**：直接从 Z-tokens 生成下游任务答案（如 QA、摘要）。
        2.  **作为重构器（Reconstructor）**：将 Z-tokens 还原为原始文本，支持在 Z-token 空间进行抽象推理后再还原。
    *   **词表约束**：解码时将输出限制在原始词表 $V_{base}$ 内，强制模型将内部抽象语言翻译回自然语言。
*   **训练策略**：引入**计划采样（Schedule Sampling）**，在训练中逐步从 Teacher Forcing 转向自由解码，以缓解自回归生成中的曝光偏差（Exposure Bias）。

#### 6. 主要结论与发现
*   **高效压缩**：在保持高性能的同时，实现了最高 **18 倍** 的 Token 缩减。
*   **性能优异**：在重构任务中 BLEU-4 达到 99.31；在长文本 QA 任务中，压缩后的表现接近甚至在某些指标上超过了原始全量输入。
*   **推理加速**：推理速度提升了 **4.6 倍**（直接在 Z 空间推理），显著降低了显存占用。
*   **Z-token 的多义性**：发现 Z-tokens 具有类似人类语言的“多义性”，即相同的 Z-token 在不同上下文中代表不同含义，这种编码方式比固定映射更高效且具有语义一致性。

#### 7. 优点与亮点
*   **变长压缩**：不同于以往固定压缩率的方法，该模型能根据内容密度动态调整，语义复杂处多分配 Token，冗余处少分配。
*   **自表达性**：利用 LLM 自身的“内部语言”进行压缩，无需外部复杂的编码器，保持了模型架构的简洁性。
*   **可解释性**：Z-tokens 是离散符号，比连续向量更易于观察和分析其语义对应关系。
*   **端到端一致性**：通过计划采样和词表约束，解决了压缩-解压过程中的漂移问题。

#### 8. 不足与局限
*   **训练成本**：虽然使用了 LoRA，但仍需针对特定任务或领域进行微调，无法完全做到“即插即用”。
*   **长程依赖协调**：在滑动窗口模式下，虽然有一致性约束，但如何实现跨窗口的全局 Z-token 协同仍有提升空间。
*   **任务感知能力**：目前的压缩过程主要是通用的语义蒸馏，未来若能根据具体任务（如只关注事实或只关注逻辑）进行任务感知的压缩，效果可能更佳。
*   **曝光偏差**：尽管引入了计划采样，但在极长序列的自由解码中，错误累积的风险依然存在。
