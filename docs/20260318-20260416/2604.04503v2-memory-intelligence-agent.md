## 摘要
深度研究智能体 (DRA) 将大语言模型 (LLM) 推理与外部工具相结合。记忆系统使 DRA 能够利用历史经验，这对于高效推理和自主进化至关重要。现有方法依赖于从记忆中检索相似轨迹来辅助推理，但存在记忆进化效率低下以及存储和检索成本增加等关键局限。为解决这些问题，我们提出了一种新型的记忆智能体 (MIA) 框架，由“管理者-规划者-执行者” (Manager-Planner-Executor) 架构组成。记忆管理者是一个非参数化记忆系统，可存储压缩的历史搜索轨迹。规划者是一个参数化记忆智能体，可为问题生成搜索计划。执行者是另一个在搜索计划指导下搜索和分析信息的智能体。为了构建 MIA 框架，我们首先采用交替强化学习范式来增强规划者与执行者之间的协作。此外，我们使规划者能够在测试时学习过程中持续进化，在不中断推理过程的情况下随推理同步进行实时更新。此外，我们在参数化记忆和非参数化记忆之间建立了双向转换循环，以实现高效的记忆进化。最后，我们引入了反思和无监督判断机制，以增强在开放世界中的推理和自我进化能力。在 11 个基准测试上的广泛实验证明了 MIA 的优越性。

## Abstract
Deep research agents (DRAs) integrate LLM reasoning with external tools. Memory systems enable DRAs to leverage historical experiences, which are essential for efficient reasoning and autonomous evolution. Existing methods rely on retrieving similar trajectories from memory to aid reasoning, while suffering from key limitations of ineffective memory evolution and increasing storage and retrieval costs. To address these problems, we propose a novel Memory Intelligence Agent (MIA) framework, consisting of a Manager-Planner-Executor architecture. Memory Manager is a non-parametric memory system that can store compressed historical search trajectories. Planner is a parametric memory agent that can produce search plans for questions. Executor is another agent that can search and analyze information guided by the search plan. To build the MIA framework, we first adopt an alternating reinforcement learning paradigm to enhance cooperation between the Planner and the Executor. Furthermore, we enable the Planner to continuously evolve during test-time learning, with updates performed on-the-fly alongside inference without interrupting the reasoning process. Additionally, we establish a bidirectional conversion loop between parametric and non-parametric memories to achieve efficient memory evolution. Finally, we incorporate a reflection and an unsupervised judgment mechanisms to boost reasoning and self-evolution in the open world. Extensive experiments across eleven benchmarks demonstrate the superiority of MIA.

#### 1. 核心问题与整体含义
论文针对**深度研究智能体（Deep Research Agents, DRAs）**在处理复杂、长程任务时记忆系统的局限性展开研究。
*   **研究动机**：现有的智能体记忆系统多依赖于检索长上下文（Long-context），这会导致注意力稀释、噪声干扰、存储成本高昂以及检索效率低下。
*   **核心问题**：如何构建一个既能高效存储历史经验，又能实现自主进化，且不干扰当前推理过程的记忆框架？

#### 2. 方法论
MIA 提出了一个**管理者-规划者-执行者（Manager-Planner-Executor）**的解耦架构：
*   **Memory Manager（非参数化记忆）**：负责将冗长的历史搜索轨迹压缩为结构化的“工作流（Workflow）”摘要，减少存储压力并提高检索精度。
*   **Planner（参数化记忆）**：作为智能体的“大脑”，通过强化学习将历史经验内化为模型参数。它负责分析问题并生成分步搜索计划。
*   **Executor（执行终端）**：负责具体操作，根据 Planner 的计划调用外部工具（如搜索引擎、图像搜索），并进行多轮 ReAct 推理。
*   **关键技术细节**：
    *   **交替强化学习（Alternating RL）**：基于 GRPO 算法，交替训练 Executor（使其学会遵循计划）和 Planner（使其学会吸收记忆并优化规划）。
    *   **测试时学习（Test-time Learning, TTL）**：在推理阶段实时更新 Planner 的参数，实现“边推理边进化”。
    *   **双向记忆转换**：在非参数化的“显式案例”和参数化的“隐式知识”之间建立循环。
    *   **无监督进化机制**：引入类似学术评审的 **Reviewer-AC 机制**，通过逻辑一致性、信息可信度和结果有效性三个维度，在没有标准答案的情况下实现自主学习。

#### 6. 主要结论与发现
*   **性能显著提升**：MIA 将 GPT-5.4 在 LiveVQA 和 HotpotQA 上的表现分别提升了 9% 和 6%。
*   **以小博大**：搭载 MIA 的 **7B 模型**平均性能提升 31%，甚至在多个指标上超越了未搭载该框架的 **32B 模型**（领先约 18%）。

*   **自主进化能力**：在无监督环境下，MIA 展现了随训练迭代次数增加而性能稳步增长的特性。

#### 7. 优点
*   **架构解耦**：通过 Manager-Planner-Executor 解决了长上下文记忆的存储和检索瓶颈。
*   **实时进化**：TTL 机制允许智能体在不中断推理的情况下吸收新知识，具有极强的环境适应性。
*   **无监督框架**：创新的 Reviewer-AC 机制为智能体在缺乏标注数据的开放世界中进化提供了可行路径。

#### 8. 不足与局限
*   **推理延迟**：虽然 TTL 提高了效率，但在推理时进行参数更新（Backward pass）仍会带来额外的计算开销和延迟。
*   **依赖高阶模型**：系统的上限部分取决于作为 Judger 或 Manager 的高阶模型（如 Qwen3-32B）的判断准确性。
*   **应用领域限制**：目前主要针对“深度研究”类任务，对于需要极高实时响应（如毫秒级交互）的场景，该框架的复杂性可能是一个挑战。
