## 摘要
深度研究智能体 (DRA) 将大语言模型 (LLM) 的推理能力与外部工具相结合。记忆系统使 DRA 能够利用历史经验，这对于高效推理和自主进化至关重要。现有方法依赖于从记忆中检索相似轨迹来辅助推理，但面临记忆进化效率低下以及存储和检索成本不断增加的关键局限。为解决这些问题，我们提出了一种新型的记忆智能体 (MIA) 框架，该框架由“管理者-规划者-执行者” (Manager-Planner-Executor) 架构组成。记忆管理者是一个非参数化记忆系统，可以存储压缩后的历史搜索轨迹。规划者是一个参数化记忆智能体，能够为问题生成搜索计划。执行者是另一个在搜索计划指导下进行信息搜索和分析的智能体。为了构建 MIA 框架，我们首先采用交替强化学习范式来增强规划者与执行者之间的协作。此外，我们使规划者能够在测试时学习过程中持续进化，在不中断推理过程的情况下，随推理同步进行实时更新。此外，我们在参数化记忆和非参数化记忆之间建立了双向转换循环，以实现高效的记忆进化。最后，我们引入了反思和无监督判断机制，以提升在开放世界中的推理和自我进化能力。在 11 个基准测试上的广泛实验证明了 MIA 的优越性。

## Abstract
Deep research agents (DRAs) integrate LLM reasoning with external tools. Memory systems enable DRAs to leverage historical experiences, which are essential for efficient reasoning and autonomous evolution. Existing methods rely on retrieving similar trajectories from memory to aid reasoning, while suffering from key limitations of ineffective memory evolution and increasing storage and retrieval costs. To address these problems, we propose a novel Memory Intelligence Agent (MIA) framework, consisting of a Manager-Planner-Executor architecture. Memory Manager is a non-parametric memory system that can store compressed historical search trajectories. Planner is a parametric memory agent that can produce search plans for questions. Executor is another agent that can search and analyze information guided by the search plan. To build the MIA framework, we first adopt an alternating reinforcement learning paradigm to enhance cooperation between the Planner and the Executor. Furthermore, we enable the Planner to continuously evolve during test-time learning, with updates performed on-the-fly alongside inference without interrupting the reasoning process. Additionally, we establish a bidirectional conversion loop between parametric and non-parametric memories to achieve efficient memory evolution. Finally, we incorporate a reflection and an unsupervised judgment mechanisms to boost reasoning and self-evolution in the open world. Extensive experiments across eleven benchmarks demonstrate the superiority of MIA.

### 1. 核心问题与研究背景
*   **研究动机**：深度研究智能体（DRAs）依赖记忆系统来积累经验和优化策略。然而，现有的记忆机制（如长上下文检索）存在四大痛点：
    1.  **注意力稀释**：长上下文会分散模型对当前问题的关注。
    2.  **噪声干扰**：无关或弱相关的历史记录会降低推理质量。
    3.  **存储瓶颈**：持续增长的对话历史带来巨大的存储压力。
    4.  **检索低效**：在大规模记忆库中检索会导致计算成本和延迟增加。
*   **核心目标**：开发一种能够实现“记忆进化”且存储高效的架构，使智能体能从历史轨迹中提取“过程导向”的知识（如何做），而非仅仅是“事实导向”的知识（是什么）。

### 2. 方法论
MIA 提出了 **Manager-Planner-Executor（管理者-规划者-执行者）** 架构，核心思想是将非参数化记忆与参数化记忆相结合，并实现双向转换。

*   **关键组件**：
    *   **Memory Manager（管理者）**：非参数化系统，负责将冗长的搜索轨迹压缩为结构化的“工作流（Workflow）”摘要，并基于语义相似度、价值奖励和频率奖励进行混合检索。
    *   **Planner（规划者）**：参数化智能体，吸收历史经验生成分步搜索计划，并具备反思（Reflect）和重规划（Replan）能力。
    *   **Executor（执行者）**：操作终端，负责解析计划并调用外部工具（如搜索引擎、图像搜索）获取结果。
*   **核心技术细节**：
    *   **两阶段交替强化学习（Alternating RL）**：基于 GRPO 算法。第一阶段训练执行者遵循计划；第二阶段训练规划者吸收记忆并优化规划逻辑。
    *   **测试时学习（Test-Time Learning, TTL）**：在推理过程中实时更新规划者的参数（参数化记忆），同时将成功的轨迹提取为新工作流存入管理者（非参数化记忆）。
    *   **无监督自我进化**：引入“评审员-领域主席（Reviewer-AC）”机制，通过逻辑一致性、信息来源可靠性和结果有效性三个维度的交叉评审，在没有标准答案的情况下为 RL 提供奖励信号。

### 6. 主要结论与发现
*   **性能卓越**：MIA 显著提升了现有最强模型的上限，使 GPT-5.4 在 LiveVQA 和 HotpotQA 上分别提升了 9% 和 6%。

*   **自我进化能力**：在无监督设置下，MIA 通过 TTL 机制在多次迭代中表现出稳步增长（例如在 2Wiki 数据集上从第一轮的 71.6% 提升至第三轮的 74.7%）。
*   **记忆效率**：证明了将“非参数化工作流”转化为“参数化规划能力”能有效减少存储负担并提高推理精度。

### 7. 优点
*   **架构创新**：Manager-Planner-Executor 的解耦设计有效解决了记忆噪声和存储爆炸问题。
*   **实时性**：TTL 机制允许智能体在推理时同步进化，无需离线重新训练。
*   **鲁棒的评估**：Reviewer-AC 机制为解决 LLM 评估中的“幻觉客观性”提供了新思路，增强了无监督学习的可靠性。

### 8. 不足与局限
*   **计算延迟**：TTL 过程涉及多次 Rollout（采样）和在线参数更新，虽然提升了准确率，但会显著增加单次推理的时间开销。
*   **应用范围**：目前主要针对“深度研究”类任务（多步搜索与推理），在需要极高实时响应或简单交互的场景下，该框架可能显得过于沉重。
*   **硬件依赖**：在线更新参数对推理环境的算力（尤其是显存和计算速度）提出了更高要求。
