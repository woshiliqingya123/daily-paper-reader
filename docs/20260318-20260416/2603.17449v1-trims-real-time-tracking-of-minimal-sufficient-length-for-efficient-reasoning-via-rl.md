## 摘要
大语言模型通过长思维链（CoT）序列在复杂推理方面取得了突破。然而，这往往导致严重的推理膨胀，造成大量的计算冗余。为了最大化单位 Token 的智能（Intelligence per Token），我们引入了一个理论指标——最小充分长度（MSL）。MSL 严格刻画了在保持答案正确性的前提下的最短推理长度。我们提供了一个基于独立采样序列的递归定义，并证明了其极限的存在性，从而为推理链压缩建立了第一个可测量的下界。在分析主流 CoT 压缩策略的基础上，我们识别出了使模型能够接近 MSL 的关键结构因素。基于这些见解，我们提出了 TRiMS，它在训练过程中结合基于 MSL 的估计并采用 GRPO 算法，同时通过动态批次聚合和使用批次级标准差计算优势值，来缓解训练过程中的不稳定性。TRiMS 在所有基准测试中实现了超过 80% 的 CoT Token 缩减，并伴有轻微的准确率提升。

## Abstract
Large language models achieve breakthroughs in complex reasoning via long chain-of-thought sequences. However, this often leads to severe reasoning inflation, causing substantial computational redundancy. To maximize Intelligence per Token, we introduce a theoretical metric, MSL-Minimal Sufficient Length. MSL rigorously characterizes the shortest reasoning length that preserves answer correctness. We provide a recursive definition based on independently sampled sequences and prove the existence of its limit, establishing the first measurable lower bound for reasoning-chain compression. Building on an analysis of mainstream CoT compression strategies, we identify key structural factors enabling a model to approach MSL. Based on these insights, we propose TRiMS which employs the GRPO algorithm in conjunction with MSL-based estimation during training, while mitigating instabilities during the training process through dynamic batch aggregation and advantage computation using batch-level standard deviation. TRiMS achieves over 80% CoT token reduction with a minor accuracy boost across all benchmarks.

### 1. 核心问题与研究动机
*   **核心问题**：当前大语言模型（如 OpenAI-o1、DeepSeek-R1）通过长链条思维（CoT）提升了推理能力，但伴随而来的是严重的“推理膨胀”（Reasoning Inflation），即在简单问题上消耗过多 Token，导致计算冗余和高延迟。
*   **研究动机**：旨在提升“单位 Token 的智能”（Intelligence per Token, IPT）。研究者观察到，随着采样次数增加，正确推理路径的最短长度会趋于一个稳定极限。因此，论文试图寻找并逼近这个理论上的压缩极限——**最小充分长度（Minimal Sufficient Length, MSL）**。

### 2. 方法论
*   **核心思想**：将推理过程视为多分支决策树，定义 MSL 为在保证正确性的前提下，模型内在分布所能产生的最短 Token 序列长度。通过强化学习（RL）引导模型实时追踪并逼近这一长度。
*   **关键技术细节**：
    *   **MSL 定义**：通过对 $k$ 个独立样本的有效长度（正确则为实际长度，错误则设为最大惩罚值）取最小值，并证明当 $k \to \infty$ 时，该长度收敛于 MSL。
    *   **TRiMS 框架**：基于 GRPO（群体相对策略优化）算法。
    *   **动态批次聚合（Dynamic Batch Aggregation）**：在训练早期，许多采样组可能全是错误（全 0）或全是正确（全 1），导致梯度信号失效。该技术通过过滤这些退化组来稳定训练。
    *   **自适应截断（Adaptive Truncation）**：根据问题难度，动态选择 2048 或 4096 Token 作为截断边界，平衡计算效率与推理完整性。
    *   **批次级优势归一化（Batch-level Advantage Normalization）**：针对奖励稀疏问题，将 GRPO 原有的组内归一化改为批次内归一化，防止稀疏奖励组产生过大的梯度波动。

### 3. 实验设计
*   **数据集**：
    *   **训练集**：DeepScaleR（约 4 万个数学推理问题）。
    *   **测试集（Benchmarks）**：AIME24、AMC23、MATH-500、Minerva、OlympiadBench。
    *   **泛化性测试**：MMLU（测试域外 OOD 泛化能力）。
*   **对比方法**：LC-R1、Laser、AutoThink、AdaptThink、JET 等主流推理压缩/高效推理方法。
*   **评估指标**：准确率（Acc）、平均 Token 长度、单位 Token 智能（IPT）。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 1.5B、7B 和 14B 不同规模的模型（主要基于 DeepSeek-R1-Distill-Qwen 系列），并在最新的 Qwen3-4B 上验证了迁移性。
*   **充分性**：实验不仅对比了最终性能，还进行了消融实验（如优势归一化方式对比）、推理轨迹词汇分析（证明减少的是重复和犹豫）、难度自适应分析以及测试时缩放（Test-time Scaling）分析。
*   **客观性**：使用了多个公开权威基准，并与 2025-2026 年间最新的 SOTA 方法进行了直接对比，实验设计较为严谨。

### 6. 主要结论与发现
*   **高效压缩**：TRiMS 在 1.5B 和 7B 模型上均实现了 **80% 以上的 Token 缩减**。
*   **性能提升**：在大幅压缩长度的同时，准确率不仅没有下降，反而有轻微提升（1.5B 模型平均提升 6.8%）。
*   **IPT 飞跃**：单位 Token 智能（IPT）提升了约 6.3 倍，证明模型学会了更高效的推理方式。
*   **消除冗余**：分析显示，TRiMS 主要消除了推理中的重复、犹豫（如 "Wait", "Hmm"）和无效的回溯。

### 7. 优点
*   **理论支撑**：首次提出了 MSL 这一可测量的推理压缩下界，为 CoT 压缩提供了明确的优化目标。
*   **训练稳定性**：通过动态批次聚合和批次归一化，解决了强化学习在处理长序列、稀疏奖励时的不稳定性问题。
*   **难度自适应**：模型无需显式指令即可根据问题难度自动调整推理长度。

### 8. 不足与局限
*   **模型规模限制**：实验主要集中在 1.5B 到 14B 的中小规模模型，尚未在超大规模模型（如 70B+）上验证。
*   **领域局限**：训练数据主要集中在数学领域，虽然在 MMLU 上表现出泛化性，但在更广泛的通用对话或创意写作中的表现尚待验证。
*   **截断策略较粗糙**：目前的自适应截断采用的是两阶段或三阶段的离散值（如 2048/4096），未能完全利用 MSL 的连续性特征。
*   **提示词敏感性**：尚未研究不同 Prompt 诱导出的 MSL 差异。
