## 摘要
标准的基于 LLM 的语音识别系统通常孤立地处理话语，限制了其利用对话上下文的能力。在这项工作中，我们研究了来自前几轮的多模态上下文是否能改进基于 LLM 的 ASR，以及如何高效地表示该上下文。我们发现，在经过监督式多轮训练后，对话上下文主要有助于识别上下文实体。然而，以原始上下文为条件的开销很大，因为前几轮的音频标记序列会随着对话长度的增加而迅速增长。为了解决这个问题，我们提出了“抽象压缩”（Abstract Compression），它将前几轮的音频部分替换为固定数量的学习到的潜标记，同时显式保留相应的转录文本。在域内和域外测试集上，压缩模型以更小的前几轮音频占用空间，恢复了原始上下文条件化所带来的部分增益。我们还对压缩设置及其权衡进行了针对性分析。

## Abstract
Standard LLM-based speech recognition systems typically process utterances in isolation, limiting their ability to leverage conversational context. In this work, we study whether multimodal context from prior turns improves LLM-based ASR and how to represent that context efficiently. We find that, after supervised multi-turn training, conversational context mainly helps with the recognition of contextual entities. However, conditioning on raw context is expensive because the prior-turn audio token sequence grows rapidly with conversation length. To address this, we propose Abstract Compression, which replaces the audio portion of prior turns with a fixed number of learned latent tokens while retaining corresponding transcripts explicitly. On both in-domain and out-of-domain test sets, the compressed model recovers part of the gains of raw-context conditioning with a smaller prior-turn audio footprint. We also provide targeted analyses of the compression setup and its trade-offs.

#### 1. 核心问题与整体含义
*   **研究背景**：当前的 ASR（自动语音识别）系统，即使是基于多模态大语言模型（LLM）的系统，通常也倾向于孤立地处理每一段语音。然而，在对话场景中，历史信息（如前文提到的人名、地名、专业术语）对当前话语的准确识别至关重要。
*   **核心挑战**：在 LLM-ASR 中，音频通常被转化为长序列的 token。如果直接将多轮对话的原始音频 token 作为上下文输入，会导致 Prompt 长度迅速膨胀，引发 KV Cache 成本过高、推理延迟增加以及内存瓶颈。
*   **研究目的**：探索如何在保留对话上下文增益（尤其是对实体的识别能力）的同时，通过高效的压缩手段降低计算开销。

#### 2. 方法论
论文提出了一种名为 **“抽象压缩”（Abstract Compression）** 的框架：
*   **核心思想**：将历史对话分为“文本转录”和“音频”两部分。由于文本相对紧凑，保留原始文本；而音频 token 冗余度高，将其压缩为固定数量的潜在标记（Latent Tokens）。
*   **关键技术细节**：
    *   **压缩模块**：采用交叉注意力（Cross-Attention）机制。定义一组可学习的查询矩阵 $Q_i \in \mathbb{R}^{K \times D}$（$K$ 为压缩后的 token 数，通常远小于原始长度），通过对原始音频序列进行注意力计算，提取出 $K$ 个代表性向量。
    *   **两阶段训练策略**：
        1.  **阶段 1：对齐训练**。冻结 LLM，仅训练压缩模块。任务是让模型仅根据压缩后的 $K$ 个音频 token 完成单轮 ASR，确保压缩后的向量能被 LLM 理解。
        2.  **阶段 2：上下文微调**。联合微调压缩模块和 LLM 的音频 LoRA 参数。采用**课程学习（Curriculum Learning）**，从 0 轮上下文开始，逐渐增加到最多 10 轮，让模型学会结合历史压缩音频和当前原始音频进行识别。

#### 5. 实验数量与充分性
*   **实验规模**：研究涵盖了从单轮到多轮（最多 10 轮）的对比，并在域内和域外两个数据集上进行了验证。

#### 6. 主要结论与发现
*   **上下文的必要性**：未经多轮训练的 LLM 直接加入上下文反而会降低性能；经过监督微调（SFT）后，上下文能显著提升识别率，尤其是对**上下文实体**的识别。
*   **压缩的有效性**：抽象压缩能以极小的 token 占用（例如每轮仅 16 个 token，压缩率极高）恢复原始上下文带来的大部分性能增益。
*   **饱和效应**：性能增益主要来自最近的几轮对话，通常在 5 轮上下文后收益趋于平缓。
*   **对齐的重要性**：阶段 1 的对齐训练对压缩模块的成功至关重要，但阶段 1 的重建精度并不完全等同于阶段 2 的上下文利用能力。

#### 7. 优点
*   **针对性强**：敏锐地观察到音频 token 是长上下文 ASR 的主要负担，并提出了非对称压缩方案（压缩音频，保留文本）。
*   **系统友好**：将变长的音频转化为固定长度的 token，使得推理时的计算开销和内存占用更加稳定、可预测。
*   **两阶段策略**：通过课程学习和对齐训练，有效地解决了多模态长序列训练难的问题。

#### 8. 不足与局限
*   **性能损失**：尽管压缩模型表现优异，但与使用“原始全量音频”的上下文模型相比，仍存在一定的性能差距。
*   **缺乏实测延迟数据**：论文主要以 token 数量作为效率的代理指标，未提供在实际硬件上的推理延迟（Latency）或显存占用（VRAM）的具体缩减数值。
*   **模型单一性**：实验仅基于 Phi-4-Multimodal 模型，其结论在其他架构（如基于 Encoder-Decoder 的 Whisper 或其他超大规模多模态模型）上的适用性有待验证。
