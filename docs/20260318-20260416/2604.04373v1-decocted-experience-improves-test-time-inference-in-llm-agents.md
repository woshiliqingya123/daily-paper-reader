## 摘要
人们对在不更新模型参数的情况下改进大语言模型（LLMs）的兴趣日益浓厚。一个公认的方向是测试时缩放（test-time scaling），即通过增加推理时的计算量（例如更长的推理、采样或搜索）来提高性能。然而，对于复杂的推理和智能体任务，盲目地缩放测试时计算量会大幅增加成本，且仍可能在次优探索上浪费预算。在本文中，我们探索将“上下文”作为提高 LLM 性能的补充缩放维度，并系统地研究如何构建更好的输入，通过“经验”来引导推理。我们表明，有效的上下文构建关键取决于“提炼经验”（decocted experience）。我们对经验增强型智能体进行了详细分析，研究了如何从经验中推导出上下文、性能如何随经验积累而缩放、优质上下文的特征，以及哪些数据结构能最好地支持上下文构建。我们将“提炼经验”确定为有效上下文构建的关键机制：从经验中提取精华，连贯地组织经验，并检索显著信息以构建有效的上下文。我们在推理和智能体任务（包括数学推理、网页浏览和软件工程）中验证了我们的发现。

## Abstract
There is growing interest in improving LLMs without updating model parameters. One well-established direction is test-time scaling, where increased inference-time computation (e.g., longer reasoning, sampling, or search) is used to improve performance. However, for complex reasoning and agentic tasks, naively scaling test-time compute can substantially increase cost and still lead to wasted budget on suboptimal exploration. In this paper, we explore \emph{context} as a complementary scaling axis for improving LLM performance, and systematically study how to construct better inputs that guide reasoning through \emph{experience}. We show that effective context construction critically depends on \emph{decocted experience}. We present a detailed analysis of experience-augmented agents, studying how to derive context from experience, how performance scales with accumulated experience, what characterizes good context, and which data structures best support context construction. We identify \emph{decocted experience} as a key mechanism for effective context construction: extracting essence from experience, organizing it coherently, and retrieving salient information to build effective context. We validate our findings across reasoning and agentic tasks, including math reasoning, web browsing, and software engineering.

#### 1. 核心问题与研究动机
*   **核心问题**：如何在不更新模型参数的前提下，通过优化“上下文（Context）”这一维度来提升 LLM 智能体在复杂任务中的表现？
*   **研究动机**：当前的测试时扩展（Test-time Scaling）主要集中在增加计算量（如采样、搜索），但这在复杂智能体任务中成本极高且容易产生无效探索。作者认为，**上下文**是另一个重要的扩展轴。通过从过往经验中“提炼”出高质量的输入，可以引导模型更高效地推理，避免盲目增加输出预算。

#### 2. 方法论：提炼经验（Decocted Experience）
核心思想是将原始的、冗长的交互经验转化为精炼、结构化的知识，主要包含以下三个关键技术环节：
*   **经验教训蒸馏（Lesson Distillation）**：智能体对自身的原始轨迹（Trajectory）进行反思，提取出可复用的策略、工作流和应避免的坑（Pitfalls），将冗长的交互记录压缩为简洁的“教训”。
*   **存储整合（Memory Consolidation）**：利用 K-means 聚类算法对经验库进行去重和压缩。研究发现，存储规模并非越大越好，适度的整合能减少冗余并保留多样性，存在一个性能“甜点区”。
*   **分层概念树（Hierarchical Concept Tree）**：
    *   **构建**：通过 LLM 提取经验的“概念描述”（Topic/Pattern/Technique），利用分层聚类构建树状结构。
    *   **检索**：在测试时，先定位相关的叶节点（概念群），再由 LLM 进行重排序（Re-ranking），从而在保证相关性的同时提升上下文的多样性。
*   **理论支撑**：提出命题 4.1，通过信息论证明：上下文对输出轨迹的信息增益（Information Gain）越高，推理时的预期输出长度（搜索空间）就越短，从而提高效率。

#### 6. 主要结论与发现
*   **教训优于原始经验**：在网页浏览和软件工程等噪声较大的任务中，蒸馏后的教训显著优于原始轨迹；而在数学推理中，原始轨迹提供的详细步骤仍具竞争力。
*   **上下文缩放效应**：增加检索到的教训数量（K 值）能持续提升性能，且比原始经验更具鲁棒性（原始经验过多会导致上下文过长且引入噪声）。
*   **存储不是越大越好**：过度增加存储规模会降低检索到的上下文多样性。适度的存储整合（Consolidation）能达到最佳性能。
*   **相关性与多样性的权衡**：有效的上下文需要在与问题的相关性及解题策略的多样性之间取得平衡（实验表明 $\lambda=0.6$ 时相关性最高）。

#### 7. 优点
*   **视角新颖**：将上下文视为与计算量并行的“缩放轴”，为提升智能体性能提供了低成本的新路径。
*   **理论与实践结合**：不仅提出了分层概念树等实用工具，还通过信息增益理论解释了为什么好的上下文能提高推理效率。
*   **跨领域验证**：在数学、网页、代码三个截然不同的领域均验证了有效性。

#### 8. 不足与局限
*   **自经验依赖**：实验主要基于“自经验（Self-experience）”，即模型学习自己过去的记录。对于模型完全无法处理的全新领域，如何获取初始的高质量经验未深入探讨。
