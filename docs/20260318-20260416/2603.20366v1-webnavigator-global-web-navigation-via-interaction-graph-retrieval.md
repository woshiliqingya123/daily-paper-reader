## 摘要
尽管自主网页导航取得了显著进展，但当前方法在复杂网页环境中的表现仍远未达到人类水平。我们认为，这一局限性源于“拓扑盲区”（Topological Blindness），即智能体在无法获取环境全局拓扑结构的情况下，被迫通过试错进行探索。为了克服这一局限，我们推出了 WebNavigator，它将网页导航从概率性探索重构为确定性的检索与路径规划。WebNavigator 在线下通过零 Token 开销的启发式探索构建交互图（Interaction Graphs），并在联机状态下实现“检索-推理-传送”（Retrieve-Reason-Teleport）工作流以进行全局导航。WebNavigator 在 WebArena 和 OnlineMind2Web 上达到了最先进的性能。在 WebArena 多站点任务中，WebNavigator 实现了 72.9% 的成功率，比企业级智能体的性能提高了一倍以上。这项工作揭示了拓扑盲区，而非单纯的模型推理能力，是自主网页导航中一个被低估的瓶颈。

## Abstract
Despite significant advances in autonomous web navigation, current methods remain far from human-level performance in complex web environments. We argue that this limitation stems from Topological Blindness, where agents are forced to explore via trial-and-error without access to the global topological structure of the environment. To overcome this limitation, we introduce WebNavigator, which reframes web navigation from probabilistic exploration into deterministic retrieval and pathfinding. WebNavigator constructs Interaction Graphs via zero-token cost heuristic exploration offline and implements a Retrieve-Reason-Teleport workflow for global navigation online. WebNavigator achieves state-of-the-art performance on WebArena and OnlineMind2Web. On WebArena multi-site tasks, WebNavigator achieves a 72.9\% success rate, more than doubling the performance of enterprise-level agents. This work reveals that Topological Blindness, rather than model reasoning capabilities alone, is an underestimated bottleneck in autonomous web navigation.

### 2. 方法论
WebNavigator 框架分为两个阶段：
*   **阶段一：离线交互图构建（Offline Interaction Graph Construction）**
    *   **核心思想**：在任务执行前，使用启发式引擎自动探索网站。
    *   **关键技术**：采用**自适应广度优先搜索（Adaptive BFS）**。通过对比父子节点的 DOM 树差异（Structural Differencing），仅探索新出现的交互元素，从而实现零 Token 成本的离线探索。
    *   **产出**：构建一个有向图 $G=(V, E)$，节点 $V$ 是页面状态（截图、DOM、A11y 树），边 $E$ 是交互动作。所有节点被索引至向量数据库。
*   **阶段二：在线检索增强导航（Online Retrieval-Augmented Navigation）**
    *   **工作流（Retrieve-Reason-Teleport）**：
        1.  **检索（Retrieve）**：根据任务意图生成查询，利用多模态 Late-interaction 检索技术从图中召回 Top-k 个候选页面。
        2.  **推理（Reason）**：多模态 LLM 作为选择器，从候选页中识别出最符合目标的页面。
        3.  **传送（Teleport）**：利用图算法计算当前位置到目标页的最短路径，并自动执行动作序列，实现“零 Token 成本”的快速跳转。
*   **动作空间**：封装了 `navigate(domain, query)` 高级动作，将动作空间压缩至仅 6 个，降低了决策复杂度。

### 8. 不足与局限
*   **内容时效性**：离线构建的交互图无法实时捕捉网站内容的动态变化（例如新发布的帖子或商品），虽然有增量更新机制，但仍存在延迟。
*   **探索覆盖率**：如果离线探索未能覆盖到某些深层或特定交互触发的页面，智能体将无法通过检索到达这些位置。
*   **环境依赖**：对于结构极度不稳定或具有强反爬机制的网站，离线图的构建和维护成本会增加。
*   **安全性风险**：自动化探索可能触发网站的敏感操作（如删除账号），需严格配置黑名单。
