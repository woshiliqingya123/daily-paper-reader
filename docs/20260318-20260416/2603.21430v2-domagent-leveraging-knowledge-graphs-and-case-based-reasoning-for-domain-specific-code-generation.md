## 摘要
大语言模型（LLMs）在代码生成方面展现出了卓越的能力。然而，由于大多数 LLM 是在公共领域语料库上训练的，直接将其应用于现实世界的软件开发往往成功率较低，因为这些场景通常需要特定领域的知识。特别是，特定领域任务通常需要高度专业化的解决方案，而这些方案在通用 LLM 的训练数据中往往代表性不足甚至完全缺失。为了应对这一挑战，我们提出了 DomAgent，这是一种自主编程智能体，通过结构化推理和针对性检索，使 LLM 能够生成领域自适应的代码，从而弥补这一差距。DomAgent 的核心组件是 DomRetriever，这是一个新颖的检索模块，它通过结合概念理解与经验案例，模拟人类学习特定领域知识的方式。它动态地将自顶向下的知识图谱推理与自底向上的基于案例的推理相结合，实现了结构化知识与代表性案例的迭代检索与综合，从而确保了上下文相关性和广泛的任务覆盖范围。DomRetriever 既可以作为 DomAgent 的一部分运行，也可以独立与任何 LLM 配合使用，以实现灵活的领域自适应。我们在数据科学领域的开放基准数据集（DS-1000）上评估了 DomAgent，并进一步将其应用于现实世界的卡车软件开发任务。实验结果表明，DomAgent 显著增强了特定领域的代码生成能力，使小型开源模型在复杂的现实应用中能够缩小与大型专有 LLM 之间的大部分性能差距。代码可在以下地址获取：https://github.com/Wangshuaiia/DomAgent。

## Abstract
Large language models (LLMs) have shown impressive capabilities in code generation. However, because most LLMs are trained on public domain corpora, directly applying them to real-world software development often yields low success rates, as these scenarios frequently require domain-specific knowledge. In particular, domain-specific tasks usually demand highly specialized solutions, which are often underrepresented or entirely absent in the training data of generic LLMs. To address this challenge, we propose DomAgent, an autonomous coding agent that bridges this gap by enabling LLMs to generate domain-adapted code through structured reasoning and targeted retrieval. A core component of DomAgent is DomRetriever, a novel retrieval module that emulates how humans learn domain-specific knowledge, by combining conceptual understanding with experiential examples. It dynamically integrates top-down knowledge-graph reasoning with bottom-up case-based reasoning, enabling iterative retrieval and synthesis of structured knowledge and representative cases to ensure contextual relevance and broad task coverage. DomRetriever can operate as part of DomAgent or independently with any LLM for flexible domain adaptation. We evaluate DomAgent on an open benchmark dataset in the data science domain (DS-1000) and further apply it to real-world truck software development tasks. Experimental results show that DomAgent significantly enhances domain-specific code generation, enabling small open-source models to close much of the performance gap with large proprietary LLMs in complex, real-world applications. The code is available at: https://github.com/Wangshuaiia/DomAgent.

#### 1. 核心问题与整体含义（研究动机和背景）
通用大语言模型（LLMs）在处理特定领域（Domain-Specific）的代码生成任务时面临巨大挑战。主要原因在于：
*   **领域知识匮乏**：训练数据中缺乏特定行业的第三方库（如汽车工业的内部 API）和专业逻辑。
*   **上下文适配能力不足**：难以将通用编程知识转化为符合特定工作流要求的代码。
*   **微调成本高昂**：针对不断更新的领域库进行全量微调既昂贵又难以维护。
**DomAgent** 的提出旨在通过模拟人类“概念理解（自顶向下）+ 经验学习（自底向上）”的学习模式，利用检索增强生成（RAG）技术弥补 LLM 的领域知识短板。

#### 2. 方法论：核心思想与关键技术
DomAgent 的核心是 **DomRetriever** 模块，其工作流程分为三个阶段：

*   **基于 KG 引导的层次化案例选择（Case Base Construction）**：
    *   **锚点定位**：利用知识图谱（KG）中的软件包节点作为锚点。
    *   **功能聚类**：对软件包下的函数/属性进行语义嵌入，并使用 **$k$-means 聚类** 识别不同的功能模式。
    *   **覆盖率驱动选择**：通过计算软件包覆盖率（$\alpha$）和功能簇覆盖率（$\beta$），从原始案例库中筛选出最小化但最具代表性的案例集，确保以极小的案例规模实现极高的任务覆盖。
*   **双向检索推理（DomRetriever）**：
    *   **自顶向下（Top-down）**：通过 LLM 分类器识别任务所属包，从 KG 中检索结构化的函数定义、参数和描述。
    *   **自底向上（Bottom-up）**：基于语义相似度检索案例，并根据案例中使用的函数与 KG 检索结果的重合度（Overlap）进行重排序。
    *   **智能体审查**：推理 LLM（Reasoning LLM）作为智能体，自主调用 `SearchKG` 和 `SearchCase` 工具，并在 `<think>` 标签内对比检索到的知识与案例，过滤无关信息。
*   **智能体训练（Agent Training）**：
    *   **监督微调（SFT）**：教模型如何生成触发检索的特殊 Token。
    *   **强化学习（RL）**：采用 **GRPO（Group Relative Policy Optimization）** 算法，利用外部强大模型作为奖励模型（Reward Model），优化智能体筛选相关知识和案例的能力。

#### 7. 优点（亮点）
*   **模拟人类认知**：结合结构化知识（KG）与经验案例（CBR），比单一检索方式更符合编程逻辑。
*   **高效案例库构建**：通过 KG 结构化信息解决了案例冗余问题，降低了维护成本。

*   **实时性开销**：智能体的多步推理和工具调用会增加生成延迟，在对响应速度要求极高的实时交互场景中可能存在限制。
