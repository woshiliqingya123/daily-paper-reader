## 摘要
键值 (KV) 缓存被广泛用于加速 Transformer 推理，但其内存开销随输入长度线性增长，限制了长上下文的部署。现有的令牌剔除 (token eviction) 方法通过丢弃重要性较低的令牌来减少内存，这可以被视为一种粗粒度的降维形式，即为每个令牌分配零维度或全维度。我们提出了 MixedDimKV，一种混合维度 KV 缓存压缩方法，它在更细粒度的层面上为令牌分配维度；以及 MixedDimKV-H，它进一步集成了注意力头级别 (head-level) 的重要性信息。在长上下文基准测试上的实验表明，MixedDimKV 优于以往不依赖头级重要性分析的 KV 缓存压缩方法。在配备相同的头级重要性信息时，MixedDimKV-H 的表现始终优于 HeadKV。值得注意的是，在 LongBench 上，我们的方法仅使用 6.25% 的 KV 缓存就达到了与全注意力 (full attention) 相当的性能。此外，在“大海捞针” (Needle-in-a-Haystack) 测试中，我们的方案在 50K 上下文长度下保持了 100% 的准确率，而仅使用了低至 0.26% 的缓存。

## Abstract
Key-value (KV) caching is widely used to accelerate transformer inference, but its memory cost grows linearly with input length, limiting long-context deployment. Existing token eviction methods reduce memory by discarding less important tokens, which can be viewed as a coarse form of dimensionality reduction that assigns each token either zero or full dimension. We propose MixedDimKV, a mixed-dimension KV cache compression method that allocates dimensions to tokens at a more granular level, and MixedDimKV-H, which further integrates head-level importance information. Experiments on long-context benchmarks show that MixedDimKV outperforms prior KV cache compression methods that do not rely on head-level importance profiling. When equipped with the same head-level importance information, MixedDimKV-H consistently outperforms HeadKV. Notably, our approach achieves comparable performance to full attention on LongBench with only 6.25% of the KV cache. Furthermore, in the Needle-in-a-Haystack test, our solution maintains 100% accuracy at a 50K context length while using as little as 0.26% of the cache.

### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）支持的上下文长度不断增加，**KV Cache（键值缓存）** 带来的内存开销成为了推理效率的主要瓶颈。现有的主流压缩方案主要是“令牌剔除”（Token Eviction），即根据重要性保留或丢弃整个 Token。
*   **研究动机**：作者指出，Token Eviction 本质上是一种极端的降维方式（要么分配 0 维度，要么分配全维度）。
*   **核心问题**：能否在更细粒度的“维度”层面为不同 Token 分配预算？即重要的 Token 保留更多维度，次要的保留较低维度，从而在有限的内存预算下最大化信息保留量。

### 2. 方法论：核心思想与关键技术
论文提出了 **MixedDimKV** 框架，其核心流程分为以下几个关键步骤：

*   **头级压缩策略（Head-wise Compression）**：
    不采用跨头联合压缩，而是对每个注意力头独立进行主成分分析（PCA）降维。这样做可以减少投影矩阵的内存开销，并支持不同头之间的非均匀预算分配。
*   **准确率损失评分（Accuracy Loss Score）**：
    设计了一种度量指标来量化压缩某个 Token 导致的注意力输出偏差。该指标综合考虑了：
    1.  Token 的注意力权重（Key 的影响）。
    2.  Value 向量的幅值。
    3.  不同维度下的固有可压缩性。
    算法通过计算注意力输出偏差的上界，并利用局部窗口（Local Window）内的查询进行批量化高效计算。
*   **潜在维度分配优化（Latent Dimension Allocation）**：
    将维度分配建模为一个受限优化问题：在总内存预算下最小化总损失。
    *   **关键技术**：利用长序列下原问题与拉格朗日对偶问题之间间隙（Duality Gap）极小的特性，采用**二分查找（Bisection Search）**快速寻找最优的拉格朗日乘子，从而确定每个 Token 的最优维度。
*   **变体 MixedDimKV-H**：
    进一步整合了现有的“头级重要性分析”（如 HeadKV 的离线分析结果），在头之间和头内部同时进行优化。
