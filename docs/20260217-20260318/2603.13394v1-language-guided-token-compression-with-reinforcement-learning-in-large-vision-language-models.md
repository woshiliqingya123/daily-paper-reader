## 摘要
大语言视觉模型 (LVLMs) 由于处理大量视觉 Token 而产生巨大的推理成本。现有方法通常难以将渐进式视觉 Token 缩减建模为具有序列依赖性的多步决策过程，且往往依赖于缺乏针对复杂推理轨迹进行自适应优化的手工设计评分规则。为了克服这些局限性，我们提出了 TPRL，这是一个强化学习框架，通过与最终任务性能直接挂钩的语言引导序列优化来学习自适应剪枝轨迹。我们将视觉 Token 剪枝建模为具有显式状态转移的序列决策过程，并采用自监督自编码器将视觉 Token 压缩为紧凑的状态表示，以实现高效的策略学习。剪枝策略通过从演示中学习进行初始化，随后使用近端策略优化 (PPO) 进行微调，以共同优化任务准确性和计算效率。我们的实验结果表明，TPRL 在推理过程中去除了高达 66.7% 的视觉 Token，并实现了高达 54.2% 的 FLOPs 减少，同时保持了近乎无损的平均准确率下降（仅 0.7%）。代码已发布在 https://github.com/MagicVicCoder/TPRL。

## Abstract
Large Vision-Language Models (LVLMs) incur substantial inference costs due to the processing of a vast number of visual tokens. Existing methods typically struggle to model progressive visual token reduction as a multi-step decision process with sequential dependencies and often rely on hand-engineered scoring rules that lack adaptive optimization for complex reasoning trajectories. To overcome these limitations, we propose TPRL, a reinforcement learning framework that learns adaptive pruning trajectories through language-guided sequential optimization tied directly to end-task performance. We formulate visual token pruning as a sequential decision process with explicit state transitions and employ a self-supervised autoencoder to compress visual tokens into a compact state representation for efficient policy learning. The pruning policy is initialized through learning from demonstrations and subsequently fine-tuned using Proximal Policy Optimization (PPO) to jointly optimize task accuracy and computational efficiency. Our experimental results demonstrate that TPRL removes up to 66.7\% of visual tokens and achieves up to a 54.2\% reduction in FLOPs during inference while maintaining a near-lossless average accuracy drop of only 0.7\%. Code is released at \href{https://github.com/MagicVicCoder/TPRL}{\textcolor{mypink}{https://github.com/MagicVicCoder/TPRL}}.

### 论文总结：大语言视觉模型中基于强化学习的语言引导 Token 压缩 (TPRL)

#### 1. 核心问题与整体含义（研究动机和背景）
现代大语言视觉模型 (LVLM) 为了捕捉细粒度空间细节，通常采用高分辨率输入，导致生成的视觉 Token 数量庞大。这带来了极高的推理延迟和内存消耗。
*   **现有局限性**：目前的 Token 剪枝或合并方法多依赖于启发式规则（如注意力权重或特征相似度），存在两个核心问题：
    1.  **任务无关性**：剪枝决策与下游语言生成任务的语义需求脱节。
    2.  **单步决策**：大多将剪枝视为一次性操作，忽略了视觉信息提取是一个具有序列依赖性的渐进过程。
*   **研究目标**：提出一种受语言引导的、基于强化学习 (RL) 的自适应剪枝框架，使模型能根据具体问题动态决定保留哪些视觉 Token。

#### 2. 方法论：核心思想与关键技术
论文提出了 **TPRL (Language-Guided Token Compression with Reinforcement Learning)** 框架，将 Token 缩减建模为**马尔可夫决策过程 (MDP)**。

*   **核心思想**：通过强化学习优化剪枝轨迹，使保留的 Token 既具有视觉显著性，又是回答特定文本查询所必需的。
*   **关键技术细节**：
    1.  **状态压缩 (State Compression)**：为了降低 RL 的训练难度，使用轻量级自监督**自编码器 (Autoencoder)** 将高维视觉 Token (如 1024 维) 压缩到低维潜空间 (64 维)，仅用于策略网络输入。
    2.  **语言引导的 MDP 建模**：
        *   **状态 (State)**：当前剩余 Token 的压缩表示与文本查询嵌入的组合。
        *   **动作 (Action)**：对每个 Token 做出“保留”或“剪枝”的二元决策。
        *   **奖励函数 (Reward)**：结合了任务准确率得分（由 LLM 输出评估）和计算效率（Token 减少比例）。
    3.  **三阶段训练流程**：
        *   **阶段 1**：训练自编码器以获得紧凑的状态表示。
        *   **阶段 2：从演示中学习 (LfD)**。利用现有的启发式剪枝方法生成高质量轨迹，通过监督学习为策略网络提供“热启动”，解决 RL 探索效率低的问题。
        *   **阶段 3：PPO 微调**。使用近端策略优化 (PPO) 算法，根据最终任务奖励对策略进行端到端微调。
    4.  **推理协议**：虽然训练是多步的，但推理时采用“一次性 (One-shot)”剪枝，通过策略网络输出的概率阈值直接生成掩码。

*   **高效压缩**：TPRL 在 LLaVA-1.5-7B 上可移除 **66.7%** 的视觉 Token，减少 **54.2%** 的 FLOPs。

#### 7. 优点（亮点）
*   **任务感知决策**：不同于以往只看图像特征的方法，TPRL 真正实现了“根据问题找答案相关的图像区域”。
*   **多步建模优势**：将剪枝视为序列决策，能够比单步方法更精细地捕捉 Token 间的依赖关系。
*   **训练稳定性**：通过 LfD（从演示学习）成功解决了在大规模离散动作空间中进行 RL 训练难收敛的问题。
*   **推理友好**：虽然训练过程复杂，但推理时增加的计算开销极低（得益于状态压缩和轻量级策略网络）。

#### 8. 不足与局限
*   **训练成本**：相比于即插即用的启发式方法，TPRL 需要三阶段训练（AE、监督预训练、RL 微调），计算资源投入较大。
*   **阈值敏感性**：推理时的性能高度依赖于手动设置的概率阈值 $\tau$，不同任务可能需要微调该参数以达到最优平衡。
*   **动态性限制**：虽然策略是自适应的，但目前主要针对静态图像问答，对于视频等具有更高时间冗余的任务，其扩展性有待进一步验证。
