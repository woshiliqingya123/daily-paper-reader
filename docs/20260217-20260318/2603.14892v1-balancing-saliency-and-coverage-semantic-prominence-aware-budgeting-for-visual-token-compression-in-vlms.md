## 摘要
大型视觉语言模型 (VLM) 通过利用高分辨率视觉输入实现了强大的多模态理解能力，但由此产生的大量视觉 Token 造成了主要的计算瓶颈。近期的研究通过视觉 Token 压缩来缓解这一问题，通常基于显著性、多样性或两者的固定组合来压缩 Token。我们观察到，语义显著性的分布在不同样本之间存在显著差异，导致局部显著性保留与全局覆盖范围之间的最佳权衡各不相同。这一观察表明，在所有样本中应用静态压缩策略可能是次优的。受此启发，我们提出了 PromPrune，这是一个样本自适应的视觉 Token 选择框架，由语义显著性感知的预算分配和两阶段选择流水线组成。我们的方法根据每个样本的语义显著性分布，自适应地平衡局部显著性保留和全局覆盖范围。通过在局部显著区域和全局多样化区域之间分配 Token 预算，我们的方法即使在高压缩率下也能保持强大的性能。在 LLaVA-NeXT-7B 上，我们的方法在保留 97.5% 原始准确率的同时，减少了 88% 的 FLOPs 和 22% 的预填充延迟。

## Abstract
Large Vision-Language Models (VLMs) achieve strong multimodal understanding capabilities by leveraging high-resolution visual inputs, but the resulting large number of visual tokens creates a major computational bottleneck. Recent work mitigates this issue through visual token compression, typically compressing tokens based on saliency, diversity, or a fixed combination of both. We observe that the distribution of semantic prominence varies substantially across samples, leading to different optimal trade-offs between local saliency preservation and global coverage. This observation suggests that applying a static compression strategy across all samples can be suboptimal. Motivated by this insight, we propose PromPrune, a sample-adaptive visual token selection framework composed of semantic prominence-aware budget allocation and a two-stage selection pipeline. Our method adaptively balances local saliency preservation and global coverage according to the semantic prominence distribution of each sample. By allocating token budgets between locally salient regions and globally diverse regions, our method maintains strong performance even under high compression ratios. On LLaVA-NeXT-7B, our approach reduces FLOPs by 88% and prefill latency by 22% while preserving 97.5% of the original accuracy.

### 1. 核心问题与研究动机
*   **核心问题**：大型视觉语言模型（VLM）在处理高分辨率输入时会产生海量的视觉 Token，导致推理时的计算开销（FLOPs）、预填充延迟和 KV 缓存内存占用巨大。
*   **研究动机**：现有的视觉 Token 压缩方法通常采用**静态策略**，即要么只关注局部显著性（Saliency），要么只关注全局覆盖度（Coverage/Diversity），或者以固定比例组合两者。作者发现，不同图像的“语义显著性分布”差异巨大（例如：有的图像信息集中在单个物体，有的则分散在全景），使用统一的压缩比例会导致性能在不同任务间失衡。

### 2. 方法论（PromPrune 框架）
PromPrune 提出了一种**样本自适应**的压缩方案，核心包含两个阶段：
*   **语义显著性度量（谱熵 Spectral Entropy）**：
    *   利用视觉 Token 特征矩阵的奇异值分解（SVD）计算谱熵。
    *   **核心思想**：谱熵能有效反映信息的集中程度。低熵表示语义集中在少数维度/区域，高熵表示语义分布广泛。实验证明谱熵比传统的注意力熵或特征范数熵更具区分度。
*   **自适应预算分配**：
    *   通过一个 Sigmoid 映射函数，根据谱熵动态决定总预算 $T$ 中分配给“显著性 Token” ($T_{sal}$) 和“覆盖度 Token” ($T_{cov}$) 的比例。
*   **两阶段选择流水线**：
    1.  **阶段一（显著性）**：根据视觉编码器的注意力分数（如 CLS-to-patch attention），保留前 $T_{sal}$ 个最显著的 Token。
    2.  **阶段二（覆盖度）**：从剩余 Token 中，利用行列式点过程（DPP）选择 $T_{cov}$ 个 Token，以最大化特征空间的多样性，确保全局背景不丢失。

### 6. 主要结论与发现
*   **样本自适应是关键**：没有一种固定的显著性/覆盖度比例能适配所有图像。
*   **高压缩率下的优势**：在极高压缩率（如仅保留 5.6% 的 Token）下，PromPrune 的性能显著优于静态方法，保留了原模型约 93.5% - 97.5% 的能力。
*   **谱熵的有效性**：谱熵是衡量视觉信息分布密度的可靠代理指标，能够指导预算的科学分配。

### 7. 优点
*   **动态灵活性**：首次实现了根据图像内容自动调整“看局部”还是“看全局”的平衡。
*   **通用性强**：不改变 LLM 结构，兼容 FlashAttention 等优化内核，适用于多种 VLM 架构。
*   **理论扎实**：引入谱分析（SVD）来量化语义分布，比启发式规则更具科学性。

### 8. 不足与局限
*   **多图/裁剪处理**：在 LLaVA-NeXT 等采用图像裁剪（Crop）策略的模型中，目前对所有裁剪块采用相同的分配逻辑，未来若能针对每个 Crop 单独计算熵可能会更优。
*   **计算开销**：虽然 SVD 和 DPP 相比 LLM 推理很轻量，但在极其追求极致延迟的嵌入式场景下，这部分额外计算仍需优化。
*   **超参数依赖**：Sigmoid 映射函数仍依赖两个超参数（$\mu$ 和 $\tau$），虽然实验证明其具有鲁棒性，但仍需针对不同视觉编码器进行简单的预标定。
