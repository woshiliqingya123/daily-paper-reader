## 摘要
提示词长度是智能体大语言模型（LLM）工作负载中的主要瓶颈，其中重复的推理步骤和多轮调用循环会产生巨大的预填充成本。最近关于投机性预填充的研究表明，基于注意力的 Token 重要性估计可以实现免训练的提示词压缩，但这假设存在一个与目标模型共享相同分词器（tokenizer）的草稿模型。然而在实践中，智能体流水线经常使用没有同系列更小草稿模型支持的模型。在这项工作中，我们研究了跨家族投机性预填充，即使用来自一个模型家族的轻量级草稿模型为来自另一个家族的目标模型执行提示词压缩。利用与先前工作相同的投机性预填充机制，我们评估了一系列跨家族的草稿-目标组合，包括 Qwen、LLaMA 和 DeepSeek 模型。在广泛的任务中，我们发现尽管草稿模型和目标模型之间存在架构和分词器的差异，但基于注意力的 Token 重要性估计在不同模型家族之间具有可靠的可迁移性。跨模型提示词压缩在很大程度上保留了全量提示词基准性能的 90~100%，在某些情况下，由于去噪效应，准确率甚至略有提高，同时显著降低了首字延迟（TTFT）。这些结果表明，投机性预填充主要依赖于任务先验和语义结构，因此可以作为一种通用的提示词压缩原语。我们讨论了研究结果对智能体系统的启示，在这些系统中，重复的长上下文推理和异构模型栈使得跨模型提示词压缩既必要又实用。

## Abstract
Prompt length is a major bottleneck in agentic large language model (LLM) workloads, where repeated inference steps and multi-call loops incur substantial prefill cost. Recent work on speculative prefill demonstrates that attention-based token importance estimation can enable training-free prompt compression, but this assumes the existence of a draft model that shares the same tokenizer as the target model. In practice, however, agentic pipelines frequently employ models without any smaller in-family draft model. In this work, we study cross-family speculative prefill, where a lightweight draft model from one model family is used to perform prompt compression for a target model from a different family. Using the same speculative prefill mechanism as prior work, we evaluate a range of cross-family draft-target combinations, including Qwen, LLaMA, and DeepSeek models. Across a broad diversity of tasks, we find that attention-based token importance estimation transfers reliably across different model families despite differences in model architectures and tokenizers between draft and target models. Cross-model prompt compression largely retains 90~100% of full-prompt baseline performance and, in some cases, slightly improves accuracy due to denoising effects, while delivering substantial reductions in time to first token (TTFT). These results suggest that speculative prefill depends mainly on task priors and semantic structure, thus serving as a generalizable prompt compression primitive. We discuss the implications of our findings for agentic systems, where repeated long-context inference and heterogeneous model stacks make cross-model prompt compression both necessary and practical.

### 1. 核心问题与研究动机
*   **核心问题**：在智能体（Agentic）工作负载中，长提示词（Long Prompt）导致的预填充（Prefill）阶段延迟和成本极高。现有的“投机性预填充”（Speculative Prefill）技术虽然能压缩提示词，但通常要求草稿模型（Draft Model）与目标模型（Target Model）属于同一家族且共享分词器。
*   **研究动机**：现实中，许多顶尖模型（如 DeepSeek-V3/R1）缺乏同系列的小型草稿模型；同时，实际应用中常涉及异构模型栈。因此，验证“基于注意力的 Token 重要性估计”是否具有跨模型家族的可迁移性具有重要的工程意义。

### 2. 方法论
*   **核心思想**：利用一个轻量级的异构草稿模型（如 Qwen）来识别原始提示词中的关键 Token，将其保留并拼接成压缩后的文本，再交给目标模型（如 Llama 或 DeepSeek）进行最终推理。
*   **关键技术细节**：
    1.  **重要性估计**：草稿模型对全量提示词进行前向传播，利用“多步预测”（Lookahead）机制聚合多个解码步骤的注意力分数。
    2.  **聚合策略**：在层（Layer）和头（Head）维度取最大值，在 Lookahead 维度取平均值，生成每个 Token 的标量重要性得分。
    3.  **分块选择**：将 Token 序列划分为固定大小的块（Chunk），计算块平均分并保留得分最高的 Top-K 块。
    4.  **跨家族适配**：由于分词器不同，该方法在**文本层面**进行拼接。压缩后的文本块之间插入特定分隔符（如 `[...]` 或 `// omitted`），并为目标模型分配**新的连续位置 ID**，从而避开了复杂的跨分词器位置对齐问题。

    *   **InfiniteBench (Code Debug)**：测试在海量代码库中定位错误的能力。
*   **对比基准（Benchmark）**：全量提示词（Full Prompt）基准性能。
*   **模型组合**：测试了 Qwen3 (0.6B/1.7B/4B)、Llama-3.2-1B、Llama-3.1-8B 作为草稿模型，DeepSeek-V3/R1、Llama-3.1-8B、Qwen3-8B 作为目标模型的多种组合。

### 6. 主要结论与发现
*   **可迁移性**：注意力机制产生的 Token 重要性信号在不同架构和分词器之间高度可迁移，证明其反映的是通用的语义结构。
*   **性能保持**：在大多数任务中，压缩后的提示词能保留 90-100% 的原始精度。
*   **去噪效应**：在某些检索任务（如 RULER）中，压缩后的性能甚至超过全量提示词，因为压缩过程去除了干扰信息（Denoising）。
*   **效率提升**：在处理 128k 长度输入时，TTFT 降低了约 **18 倍**（从 46 秒降至 2.5 秒）。
*   **突破硬件限制**：允许在显存受限、仅支持 32k 上下文的硬件上，通过草稿模型预压缩来处理 128k 的输入。

### 7. 优点
*   **灵活性极高**：无需草稿模型与目标模型有任何血缘关系，适用于任何异构模型组合。
*   **零成本部署**：无需微调，直接利用现有的开源小模型即可实现。
*   **显著提速**：大幅削减了长文本推理中最耗时的预填充阶段延迟。

### 8. 不足与局限
*   **代码任务敏感性**：在代码调试（Code Debug）任务中，当压缩率过高（如仅保留 15%）时，准确率下降较明显（下降约 12-16%），说明代码逻辑对细粒度结构的依赖高于自然语言。
*   **分块策略简单**：目前的块选择是基于固定大小的，可能破坏某些语义单元（如函数定义）。
*   **位置信息丢失**：虽然实验显示影响较小，但重新分配连续位置 ID 理论上丢失了原始文本中的绝对距离信息。
