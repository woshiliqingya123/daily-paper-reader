## 摘要
全模态大语言模型 (OmniLLMs) 协同处理音频和视觉流，但由此产生的长多模态 Token 序列使得推理成本极其昂贵。现有的压缩方法通常依赖于固定窗口划分和基于注意力的剪枝，这忽略了视听信号的分段语义结构，并在激进的 Token 缩减下表现得十分脆弱。我们提出了动态音频驱动的语义分块 (DASH)，这是一个无需训练的框架，旨在使 Token 压缩与语义结构保持一致。DASH 将音频嵌入视为语义锚点，并通过余弦相似度不连续性检测候选边界，从而诱导出动态的、变长的分段，这些分段近似于序列底层分段相干的组织结构。这些边界被投影到视频 Token 上，以建立显式的跨模态分割。在每个分段内，Token 的保留由一个三信号重要性估计器决定，该估计器融合了结构边界线索、表示独特性和基于注意力的显著性，从而减轻了仅基于注意力的选择所带来的稀疏性偏差。这种结构感知的分配在减少冗余区域的同时，保留了对转换至关重要的 Token。在 AVUT、VideoMME 和 WorldSense 上的广泛实验表明，与之前的方法相比，DASH 在保持卓越准确性的同时实现了更高的压缩率。代码可在以下网址获取：https://github.com/laychou666/DASH。

## Abstract
Omnimodal large language models (OmniLLMs) jointly process audio and visual streams, but the resulting long multimodal token sequences make inference prohibitively expensive. Existing compression methods typically rely on fixed window partitioning and attention-based pruning, which overlook the piecewise semantic structure of audio-visual signals and become fragile under aggressive token reduction. We propose Dynamic Audio-driven Semantic cHunking (DASH), a training-free framework that aligns token compression with semantic structure. DASH treats audio embeddings as a semantic anchor and detects boundary candidates via cosine-similarity discontinuities, inducing dynamic, variable-length segments that approximate the underlying piecewise-coherent organization of the sequence. These boundaries are projected onto video tokens to establish explicit cross-modal segmentation. Within each segment, token retention is determined by a tri-signal importance estimator that fuses structural boundary cues, representational distinctiveness, and attention-based salience, mitigating the sparsity bias of attention-only selection. This structure-aware allocation preserves transition-critical tokens while reducing redundant regions. Extensive experiments on AVUT, VideoMME, and WorldSense demonstrate that DASH maintains superior accuracy while achieving higher compression ratios compared to prior methods. Code is available at: https://github.com/laychou666/DASH.

全模态大语言模型（OmniLLMs）在同时处理音频和视频流时，会产生极长的 Token 序列，导致推理时的计算开销（内存和延迟）呈平方级增长。
*   **研究动机**：现有的 Token 压缩方法（如剪枝或合并）通常采用**固定窗口划分**和**单一的注意力权重**作为筛选标准。
*   **核心痛点**：这种“一刀切”的方法忽略了视听信号的语义结构（如说话停顿、场景切换）。在激进压缩（如仅保留 25% Token）时，固定窗口会切断语义连续性，而稀疏的注意力机制容易漏掉关键的转折点信息。

### 2. 方法论
DASH 提出了一种**无需训练（Training-free）**的结构感知压缩框架，核心思想是将音频作为“语义锚点”来引导跨模态的动态分块与压缩。

*   **动态语义分块（Dynamic Semantic Chunking）**：
    *   利用音频编码器输出的嵌入向量，计算相邻 Token 间的余弦相似度。
    *   当相似度出现剧烈下降时，判定为语义边界（如语速变化、话题切换），从而形成变长的动态分块。
*   **跨模态边界投影（Audio-Driven Visual Segmentation）**：
    *   通过时间比例映射，将音频检测到的语义边界投影到视频 Token 序列上，实现音视频在语义层面的显式对齐。
*   **三信号融合评分（Tri-signal Fusion Scoring）**：
    *   **结构边界概率**：优先保留处于语义转折点附近的 Token。
    *   **多尺度高斯独特性**：利用密度峰值聚类原理，通过多尺度高斯核衡量 Token 的表征独特性，保留信息量大的 Token。
    *   **注意力显著性**：结合模型原始的注意力分数。
*   **边界感知视频压缩**：根据音频段的信息密度动态调整视频压缩率，并对边界帧进行额外保护，防止关键视觉转折丢失。

### 3. 实验设计
*   **数据集/场景**：
    *   **AVUT**：音频中心化的视频理解基准（包含事件定位、对象匹配等 6 个任务）。
    *   **VideoMME**：综合性视频理解评估基准。
    *   **WorldSense**：评估全模态模型在 8 个真实世界领域（如科技、体育、音乐）的理解能力。

*   **对比方法**：Random（随机剪枝）、FastV（视觉剪枝）、DyCoke（动态压缩）、OmniZip（之前的全模态压缩 SOTA）。

*   **硬件环境**：实验使用了 **NVIDIA H20 (96GB)** GPU。
*   **算力特点**：DASH 是**无需训练**的插件式框架，不需要重新训练大模型。

### 5. 实验数量与充分性
*   **实验规模**：在三个主流基准测试上进行了全面评估，涵盖了从 15% 到 60% 的多种 Token 保留率。
*   **消融实验**：详细分析了三信号融合中各组件的贡献、边界检测算法（余弦相似度 vs 点积等）的影响，以及超参数的敏感性。

### 6. 主要结论与发现
*   **高效压缩**：DASH 在仅保留 **25%** Token 的情况下，准确度可媲美或超过保留 35% Token 的现有方法（如 OmniZip）。
*   **推理加速**：在 WorldSense 基准上，DASH 实现了高达 **3.8× 的 Prefill（预填充）加速**和 **1.7× 的端到端延迟缩减**。
*   **语义对齐的重要性**：实验证明，遵循语义边界进行分块比固定窗口更能保护叙事连续性，尤其是在处理长视频和复杂音频对话时。

### 7. 优点
*   **结构感知**：突破了传统固定窗口的限制，利用音频天然的语义节奏引导视频压缩。
*   **多维评估**：三信号融合机制克服了注意力机制过于稀疏的问题，有效“拯救”了那些注意力分低但结构意义重大的 Token。
*   **即插即用**：无需微调模型，计算开销极小，易于集成到现有的 OmniLLM 推理流水线中。

### 8. 不足与局限
*   **音频依赖性**：该方法高度依赖音频信号作为锚点。如果视频中音频缺失、噪声极大或音频与视频内容完全无关，其边界检测的有效性可能会下降。
*   **超参数固定**：虽然实验证明超参数在不同模型间具有鲁棒性，但在极端极端的长序列或特定垂直领域下，可能仍需手动微调相似度阈值。
*   **空间冗余处理**：目前主要侧重于时间维度的语义分块，对于单帧内极高分辨率带来的空间冗余，仍依赖于现有的 DPC-KNN 等通用算法，缺乏更深层的全模态空间协同优化。
