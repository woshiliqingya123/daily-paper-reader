## 摘要
键值（KV）缓存对于大语言模型（LLMs）的高效推理至关重要，但过长的上下文会显著增加 KV 缓存的内存占用。现有的 KV 缓存压缩方法通常依赖于预填充阶段 Prompt 观察窗口内的输入端注意力模式来评估 Token 的重要性。由于这些评估并非源自解码过程，它们无法为未来的生成保留关键 Token。直观上，一个有效的观察窗口应该镜像解码阶段的查询，以准确反映生成过程将关注哪些 Token。然而，在推理过程中，真实的解码查询本质上是不可获取的。为了构建伪查询来逼近真实查询，我们发现位置信息比语义内容起着更关键的作用。基于这一见解，我们提出了通过位置感知伪查询实现对齐解码过程的 KV 缓存压缩（DapQ），这是一种新颖且轻量级的逐出框架，利用位置感知伪查询来模拟输出 Token，从而为重要性评估建立有效的观察窗口。它与实际的生成上下文紧密对齐，并实现了精确的 Token 逐出。在多个基准测试和大语言模型上的广泛评估表明，DapQ 取得了优异的性能，特别是在严格的内存限制下（例如，在仅保留 3% KV 缓存预算的情况下，在 NIAH 上实现了高达 99.5% 的近乎无损性能）。

## Abstract
The Key-Value (KV) cache is crucial for efficient Large Language Models (LLMs) inference, but excessively long contexts drastically increase KV cache memory footprint. Existing KV cache compression methods typically rely on input-side attention patterns within a prompt observation window to estimate token importance during the prefill stage. They fail to preserve critical tokens for future generation since these assessments are not derived from the decoding process. Intuitively, an effective observation window should mirror the decoding-stage queries to accurately reflect which tokens the generation process will attend to. However, ground-truth decoding queries are inherently unavailable during inference. For constructing pseudo queries to approximate them, we find that positional information plays a more critical role than semantic content. Motivated by this insight, we propose decoding-aligned KV cache compression via position-aware pseudo queries (DapQ), a novel and lightweight eviction framework that leverages position-aware pseudo queries to simulate the output tokens, thereby establishing an effective observation window for importance assessment. It aligns closely with the actual generation context and enables precise token eviction. Extensive evaluations across multiple benchmarks and LLMs demonstrate that DapQ achieves superior performance, particularly under strict memory constraints (e.g., up to nearly lossless performance 99.5% on NIAH with 3% KV cache budgets).

### 论文总结：Where Matters More Than What (DapQ)

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLMs）处理的上下文长度不断增加，**KV Cache（键值缓存）** 的内存占用和计算开销成为推理效率的主要瓶颈。
*   **现有问题**：目前的 KV 缓存压缩方法（如 SnapKV、PyramidKV）通常在预填充（Prefill）阶段，利用 Prompt 末尾的一个固定观察窗口来评估 Token 的重要性。
*   **研究动机**：作者认为这种“以输入为中心”的评估方式与实际解码（Decoding）阶段的查询（Query）存在**严重不对齐**。理想情况下，应该用解码阶段的 Query 来筛选 KV，但推理时未来的 Query 是不可知的。
*   **核心发现**：论文通过实验发现，在构建模拟 Query 时，**位置信息（Positional Information）对注意力模式的影响远比语义内容（Semantic Content）更重要**。基于此，提出了 DapQ 框架。

#### 2. 方法论：核心思想与技术细节
DapQ 的核心思想是在预填充阶段构造**位置感知的伪查询（Position-aware Pseudo Queries）**，模拟未来解码步骤的注意力行为。

*   **核心流程**：
    1.  **构造伪序列**：在原始 Prompt（长度为 $L_p$）后拼接 $N$ 个伪 Token（$T_{pseudo}$）。
    2.  **位置分配**：关键步骤是给这些伪 Token 分配**未来的位置索引**，即 $[L_p, L_p + 1, \dots, L_p + N - 1]$，而不是紧随其后的物理位置。
    3.  **获取伪查询**：模型处理该扩展序列，提取这 $N$ 个位置对应的 Query 向量（$Q_{pseudo}$）。
    4.  **重要性评估**：计算 $Q_{pseudo}$ 与原始 Prompt 中所有 Key 的注意力分数。第 $j$ 个 Token 的重要性得分 $S(j)$ 是所有伪查询对其注意力分数的总和。
    5.  **逐出与解码**：保留得分最高的 Top-K 个 KV 对，剔除其余部分以及所有伪 Token，随后从位置 $L_p$ 开始正式解码。
*   **语义选择**：实验证明伪查询的语义内容不敏感，DapQ 默认采用 Prompt 的前 4 个和后 28 个 Token 拼接作为伪 Token 内容，以利用起始符的稳定性和末尾的相关性。

#### 3. 实验设计
*   **数据集/场景**：涵盖了长文本理解的五大主流基准：
    *   **LongBench / LongBenchV2**：多任务长文本理解。

    *   **HELMET**：长上下文评估集。
    *   **Needle-in-a-Haystack (NIAH)**：大海捞针压力测试。
*   **对比方法**：

*   **测试模型**：LLaMA-3-8B-Instruct, LLaMA-3.1-8B-Instruct, Qwen2.5-7B-Instruct, Qwen3-8B。

#### 5. 实验数量与充分性
*   **实验规模**：论文在 4 个主流模型系列和 5 个大型基准上进行了测试，涵盖了从 64 到 4096 不等的多种 KV 缓存预算设置。
*   **消融实验**：非常充分。作者详细探讨了伪查询的**语义内容**（随机、固定、前后拼接）、**窗口长度**（N 的大小）以及**插入位置**（位置偏移）对性能的影响。
*   **客观性**：通过计算伪查询与真实查询的余弦相似度，从理论和实证两方面证明了“位置主导”的观点，实验设计逻辑严密，对比基准公平。

#### 6. 主要结论与发现
*   **位置决定论**：Query 向量的表示受 RoPE（旋转位置编码）主导，即使语义完全错误，只要位置正确，其注意力模式与真实 Query 的相似度依然很高（比语义正确但位置错误高出 2.1 倍）。
*   **性能卓越**：DapQ 在极低预算下表现惊人。在 NIAH 测试中，仅保留 3% 的 KV 缓存（256 tokens），准确率仍高达 **99.5%**。
*   **鲁棒性**：在 LongBench 等复杂任务中，DapQ 在 64 或 128 的极小缓存预算下，性能显著优于 SnapKV 和 H2O。

#### 7. 优点（亮点）
*   **洞察深刻**：揭示了位置信息在 KV 缓存重要性评估中的核心地位，打破了以往过度关注语义特征的局限。
*   **轻量高效**：无需微调模型，无需复杂的两阶段生成（相比 LAQ++），仅通过一次预填充即可实现精准压缩。
*   **对齐解码**：通过模拟未来位置，解决了预填充与解码阶段的分布偏移问题。

#### 8. 不足与局限
*   **语义仍有残余影响**：虽然位置是主导，但实验显示语义完全无关时相似度仍有下降（从 1.0 降至 0.72），说明语义优化仍有提升空间。
*   **层间差异未深挖**：论文主要采用统一的伪查询策略，未深入探讨不同 Transformer 层对位置/语义敏感度的差异。
*   **超参数敏感性**：伪查询窗口长度 $N$ 存在最优值，过大（引入噪声）或过小（评估不足）都会导致性能下降，需针对不同模型微调。
