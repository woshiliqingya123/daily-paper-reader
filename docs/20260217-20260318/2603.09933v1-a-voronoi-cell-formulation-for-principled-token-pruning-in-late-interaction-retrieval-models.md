## 摘要
诸如 ColBERT 之类的延迟交互模型在各种检索任务中表现出极具竞争力的性能，但需要为每个文档 Token 存储稠密嵌入，从而导致巨大的索引存储开销。以往的工作试图根据统计和经验度量来剪枝低重要性的 Token 嵌入，但它们往往缺乏形式化基础或效果不佳。为了解决这些缺点，我们引入了一个基于超空间几何的框架，并将 Token 剪枝建模为嵌入空间中的 Voronoi 胞元估计问题。通过将每个 Token 的影响力解释为其 Voronoi 区域的测度，我们的方法实现了有原则的剪枝，在减小索引大小的同时保持了检索质量。通过实验，我们证明该方法不仅是一种具有竞争力的剪枝策略，而且是改进和解释稠密检索系统中 Token 级行为的有价值工具。

## Abstract
Late-interaction models like ColBERT offer a competitive performance across various retrieval tasks, but require storing a dense embedding for each document token, leading to a substantial index storage overhead. Past works address this by attempting to prune low-importance token embeddings based on statistical and empirical measures, but they often either lack formal grounding or are ineffective. To address these shortcomings, we introduce a framework grounded in hyperspace geometry and cast token pruning as a Voronoi cell estimation problem in the embedding space. By interpreting each token's influence as a measure of its Voronoi region, our approach enables principled pruning that retains retrieval quality while reducing index size. Through our experiments, we demonstrate that this approach serves not only as a competitive pruning strategy but also as a valuable tool for improving and interpreting token-level behavior within dense retrieval systems.

### 2. 方法论
*   **核心思想**：将 Token 剪枝视为一个 Voronoi 胞元估计问题。在 ColBERT 的 MaxSim 操作下，一个文档 Token 只有在它是某个查询向量的“最近邻”时才有贡献。这个“贡献区域”即为该 Token 的 Voronoi 胞元。
*   **关键技术细节**：
    *   **预期误差定义**：定义剪枝某个 Token 导致的误差为：在整个查询空间内，剪枝前后最大内积得分之差的期望值。
    *   **蒙特卡洛估计**：由于在高维空间直接积分不可行，通过在单位球面上均匀采样大量伪查询向量（$10^4$ 到 $10^5$ 个），近似计算每个 Token 的 Voronoi 区域大小及其剪枝误差。
    *   **迭代剪枝算法**：采用贪心策略，每次移除误差最小的 Token。关键在于**迭代更新**：每移除一个 Token，都会重新计算剩余 Token 的 Voronoi 胞元，因为空间结构发生了变化。
    *   **全局剪枝**：在集合层面根据误差贡献对所有 Token 进行排序，实现更高效的存储分配。

### 7. 优点
*   **理论严谨**：将直觉上的“重要性”转化为几何上的“胞元测度”，提供了坚实的数学基础。
*   **无需重训**：作为一种 Post-hoc（事后）方法，它可以直接应用于现有的预训练模型（如 ColBERTv2），无需额外的微调或架构修改。
*   **普适性强**：不依赖于特定的向量范数约束（如单位向量），适用范围比之前的 LP-Pruning 更广。

### 8. 不足与局限
*   **局部误差掩盖**：平均误差指标可能会掩盖某些小区域内的巨大误差，而这些区域可能对特定查询至关重要。
*   **代理损失**：优化目标是保持最大内积得分，这只是检索损失的一个代理指标，并非直接优化最终的排序指标。
*   **纯选择性**：该方法仅能从现有向量中“挑选”子集，无法像某些学习型方法那样通过修改嵌入空间来进一步提升“可剪枝性”。
