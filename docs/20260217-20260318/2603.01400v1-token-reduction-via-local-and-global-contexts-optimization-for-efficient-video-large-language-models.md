## 摘要
视频大语言模型 (VLLMs) 展示了强大的视频理解能力，但由于冗余的视觉 Token，面临效率低下的问题。现有的剪枝方法主要针对帧内空间冗余，或者在 LLM 内部进行具有浅层开销的剪枝，导致时空削减效果欠佳，且未能充分利用长上下文的可压缩性。这些方法通常会丢弃来自合并或剪枝 Token 的细微但具有信息量的上下文。在本文中，我们提出了一种新视角，通过局部-全局最优传输 (AOT) 精细构建帧内和帧间的 Token 锚点 (Anchors)，以全面聚合信息丰富的上下文。具体而言，我们首先在注意力引导下在每帧内建立局部和全局感知的 Token 锚点，随后通过最优传输聚合来自被剪枝 Token 的信息上下文，从而构建帧内 Token 锚点。然后，基于时间视频片段，每个片段的第一帧将被视为关键帧锚点，通过最优传输汇集来自连续帧的相似信息，同时保留独特的 Token 以表示时间动态，从而以无需训练的方式实现高效的 Token 削减。广泛的评估表明，我们提出的 AOT 在领先的视频 LLM 上，在各种短视频和长视频基准测试中均获得了具有竞争力的性能，在保持时间与视觉保真度的同时，显著提升了计算效率。项目主页：https://tyroneli.github.io/AOT。

## Abstract
Video Large Language Models (VLLMs) demonstrate strong video understanding but suffer from inefficiency due to redundant visual tokens. Existing pruning primary targets intra-frame spatial redundancy or prunes inside the LLM with shallow-layer overhead, yielding suboptimal spatiotemporal reduction and underutilizing long-context compressibility. All of them often discard subtle yet informative context from merged or pruned tokens. In this paper, we propose a new perspective that elaborates token \textbf{A}nchors within intra-frame and inter-frame to comprehensively aggregate the informative contexts via local-global \textbf{O}ptimal \textbf{T}ransport (\textbf{AOT}). Specifically, we first establish local- and global-aware token anchors within each frame under the attention guidance, which then optimal transport aggregates the informative contexts from pruned tokens, constructing intra-frame token anchors. Then, building on the temporal frame clips, the first frame within each clip will be considered as the keyframe anchors to ensemble similar information from consecutive frames through optimal transport, while keeping distinct tokens to represent temporal dynamics, leading to efficient token reduction in a training-free manner. Extensive evaluations show that our proposed AOT obtains competitive performances across various short- and long-video benchmarks on leading video LLMs, obtaining substantial computational efficiency while preserving temporal and visual fidelity. ### 1. 核心问题与整体含义（研究动机和背景）
视频大语言模型（VLLM）在理解复杂视频内容方面表现出色，但面临严重的**计算效率瓶颈**。由于视频包含大量帧，生成的视觉 Token 序列极长（动辄数万甚至百万级），导致推理时的内存占用和计算开销巨大。
*   **现有挑战**：目前的 Token 削减方法（如剪枝或合并）要么仅关注帧内空间冗余，要么在 LLM 内部进行浅层处理，往往会直接丢弃掉那些“看似不重要”但实际上包含细微关键信息的上下文，且未能充分利用视频帧间的时空相关性。
*   **研究动机**：提出一种**无需训练（Training-free）**的方法，在大幅减少 Token 数量的同时，通过优化手段将冗余 Token 中的有用信息“聚合”到保留的 Token 中，而非简单抛弃。

### 2. 论文提出的方法论：AOT
论文提出了 **AOT (Local-global Optimal Transport)** 框架，核心思想是利用**最优传输（Optimal Transport, OT）**理论来指导 Token 的压缩与信息聚合。

*   **局部-全局锚点建立（Anchor Establishment）**：
    *   **全局锚点**：基于注意力机制（如 [CLS] Token 的权重）筛选出对全局语义贡献最大的 Token。
    *   **局部锚点**：采用网格划分（AnyRes 启发），在每个局部窗口内保留关键 Token，以确保捕捉细粒度的局部细节。
*   **帧内（Intra-frame）优化聚合**：
    *   将选中的锚点 Token 和未选中的冗余 Token 视为两个离散分布。
    *   利用 **Sinkhorn-Knopp 迭代**快速求解最优传输方案（Transport Plan），将冗余 Token 的语义信息按权重“输送”并融合到锚点 Token 中。
*   **帧间（Inter-frame）动态压缩**：
    *   将视频划分为片段（Clips），以片段首帧作为时间锚点。
    *   通过 OT 衡量后续帧与锚点的相似度：相似信息被聚合到锚点中，而代表时间动态的差异化信息则作为独立 Token 保留。

### 6. 主要结论与发现
*   **高效压缩**：AOT 能够剪枝掉 **90%** 的视觉 Token，同时保留原始模型约 **97.6%** 的性能。
*   **性能反超**：在某些基准测试中，压缩后的模型性能甚至超过了原始模型。这表明 AOT 能够起到“去噪”作用，通过聚合关键信息减少了冗余 Token 对 LLM 的干扰。
*   **长视频优势**：在处理 128 帧等超长输入时，AOT 能够有效规避 LLM 的上下文长度限制，表现出比原始模型更强的鲁棒性。

### 7. 优点与亮点
*   **信息无损化处理**：不同于传统的“非留即丢”，AOT 通过最优传输实现了信息的“浓缩”，保留了细微的上下文。
*   **无需训练**：作为一种即插即用的插件，它不需要昂贵的微调成本，易于部署到现有的 VLLM 中。
*   **时空协同**：同时解决了空间冗余和时间冗余，且通过 Sinkhorn 算法保证了极高的计算效率。

### 8. 不足与局限
*   **时间锚点启发式**：帧间压缩仍依赖于片段划分和首帧锚点的启发式策略，对于场景剧烈切换或极度复杂的动态视频，时间边界的划分可能存在噪声。
*   **应用限制**：虽然在 7B 模型上表现优异，但在更大规模（如 72B）或不同架构的模型上的泛化能力仍有待进一步验证。
*   **依赖初始质量**：如果视觉编码器提取的初始特征质量较差，OT 聚合的效果可能会受到底层表征能力的限制。
