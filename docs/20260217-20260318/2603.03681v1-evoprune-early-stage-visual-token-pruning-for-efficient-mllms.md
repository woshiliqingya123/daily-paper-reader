## 摘要
多模态大语言模型（MLLMs）在视觉语言任务中表现出强大的性能，但其推理效率受到高分辨率图像和视频等复杂场景下视觉 Token 指数级增长的严重限制。现有的视觉 Token 剪枝方法主要在视觉编码之后进行，忽略了编码阶段产生的巨大计算开销。为了解决这一问题，我们提出了 EvoPrune，这是一种针对 MLLMs 的早期视觉 Token 剪枝方法，直接在视觉编码过程中执行剪枝。具体而言，EvoPrune 采用了一种由 Token 相似度、多样性和基于注意力的重要性引导的分层剪枝策略，以在选定的编码层保留最具信息量的视觉 Token。在图像和视频基准测试上的广泛实验验证了 EvoPrune 的有效性。特别是在 VideoMME 数据集上，EvoPrune 在性能下降不到 1% 的情况下实现了 2 倍的推理加速，展示了其在延迟敏感型 MLLM 部署中的潜力。

## Abstract
Multimodal Large Language Models (MLLMs) have shown strong performance in vision-language tasks, but their inference efficiency is severely limited by the exponential growth of visual tokens in complex scenarios such as high-resolution images and videos. Existing visual token pruning methods mainly operate after visual encoding, overlooking the substantial computational cost incurred during the encoding stage. To address this issue, we propose EvoPrune, an early-stage visual token pruning method for MLLMs that performs pruning directly during visual encoding. Specifically, EvoPrune employs a layer-wise pruning strategy guided by token similarity, diversity, and attention-based importance to retain the most informative visual tokens at selected encoding layers. Extensive experiments on image and video benchmarks validate the effectiveness of EvoPrune. In particular, on the VideoMME dataset, EvoPrune achieves 2$\times$ inference speedup with less than 1% performance degradation, demonstrating its potential for latency-sensitive MLLM deployment.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：多模态大语言模型（MLLM）在处理高分辨率图像和长视频时，视觉 Token 数量呈指数级增长，导致推理效率低下。
*   **研究背景**：现有的视觉 Token 剪枝方法（如基于注意力或相似度的过滤）大多发生在**视觉编码之后**。然而，随着输入规模扩大，视觉编码器（Vision Encoder）本身的计算开销已逐渐成为瓶颈。
*   **研究动机**：作者发现，如果仅在进入 LLM 前剪枝，无法缓解编码阶段的压力。因此，需要一种能在视觉编码过程中（早期阶段）直接减少 Token 数量的方案，以实现端到端的推理加速。

### 2. 方法论：核心思想与关键技术
EvoPrune 的核心思想是在视觉编码器的 Transformer 层之间进行**层级化 Token 合并**。
*   **层级剪枝策略（Layer-wise Pruning）**：在选定的编码层（如每隔一层）执行合并操作。通过实验发现，“Skip”（跳跃式）分配策略在保持性能和提升效率之间平衡最好。
*   **复合评分引导（Score-Guided Merging）**：使用一个综合评分矩阵来决定哪些 Token 对应该合并，包含三个维度：
    1.  **语义相似度（Similarity Attraction）**：计算 Token 间的余弦相似度，倾向于合并语义相近的冗余 Token。
    2.  **信息多样性（Diversity Penalty）**：引入局部密度估计，惩罚位于密集区域的 Token 合并，从而保护稀疏区域（可能包含独特信息）的 Token。
    3.  **注意力重要性（Attention Preservation）**：利用自注意力权重计算 Token 的重要性得分，并设置“关键 Token 比例（CTR）”，强制保留得分最高的 Token 不被合并。
*   **算法流程**：将 Token 集分为两个不相交的组，计算跨组的复合评分，选取评分最高的 Top-r 对进行合并，并更新 Token 表示。

*   **对比方法**：对比了 FasterVLM、VisPruner、DART、DivPrune、CDPruner 等多种 SOTA 剪枝方法。
*   **Benchmark 设定**：在不同的 Token 保留率（如保留 128、64、32 个 Token）下测试性能与延迟。

### 6. 主要结论与发现
*   **显著加速**：在 Video-MME 基准上，EvoPrune 实现了 **2 倍的端到端推理加速**，而性能下降不到 1%。
*   **早期剪枝的优势**：相比于后置剪枝方法，EvoPrune 能显著降低视觉编码器的计算耗时（加速约 1.8x）和中间模块耗时（加速约 5x）。

### 7. 优点（亮点）
*   **端到端高效**：首次系统性地解决了 MLLM 推理中被忽视的“编码器计算瓶颈”。
*   **即插即用**：无需任何微调或重新训练，可直接应用于现有的预训练 MLLM。
*   **多因子权衡**：通过结合相似度、多样性和注意力，比单一指标的剪枝更具信息保留能力。

### 8. 不足与局限
*   **架构依赖性**：实验主要基于 LLaVA 系列模型（ViT 编码器），对于其他类型的视觉骨干（如非 Transformer 架构）的适用性未做讨论。
*   **超参数敏感性**：层级分配策略和关键 Token 比例（CTR）等超参数可能需要针对不同模型进行微调以达到最优效果。
*   **极端长视频挑战**：虽然在长视频上表现良好，但对于数小时级别的超长视频，如何动态调整剪枝强度仍有待进一步探索。
