## 摘要
随着大语言模型（LLM）的上下文窗口扩展到 100K+ token，键值（KV）缓存已成为主要的内存瓶颈，近期的方法声称可以节省 80-90% 的空间且基准测试性能下降极小。我们认为这些评估忽略了一个结构性问题：注意力不仅是存储，更是路由，保留 KV 对并不保证语义的可访问性。我们提出了一种受物理学启发的 KV 压缩视角，将其视为对 token 级路由的受控扰动，并区分了保留、可访问性和利用率。通过探测多实体追踪、消歧、指代消解和多步推理的合成任务，我们发现：中度压缩在准确率损失极小的情况下降低了内部表示质量，揭示了冗余性；所有模型在 90% 压缩率附近均表现出剧烈的幻觉安全悬崖，这与全局剔除率（GER）的激增相关，暗示了语义可达性的相变；不同架构的路由动力学存在差异，LLaMA 表现出早期共识和后期多样化，而 Qwen 表现出漏斗状的后期收敛，从而导致了不同的韧性特征。除了擦除之外，我们还识别出了表示僵化（representational rigidity），即过度的多头级共识尽管保留了 token，却导致路由灵活性崩溃。这些结果表明稀疏的 token 路由结构决定了压缩容忍度，将 KV 压缩重新定义为注意力几何的结构探测，并将长上下文可扩展性与自注意力中的稀疏性和彩票假设联系起来。

## Abstract
As context windows in LLMs scale to 100K+ tokens, the key-value (KV) cache becomes the dominant memory bottleneck, with recent methods claiming 80-90% savings and minimal benchmark degradation. We argue these evaluations miss a structural issue: attention is not just storage but routing, and retaining KV pairs does not guarantee semantic accessibility. We propose a physics-inspired view of KV compression as a controlled perturbation of token-level routing, distinguishing retention, accessibility, and utilization. Using synthetic tasks probing multi-entity tracking, disambiguation, coreference, and multi-hop reasoning, we find that moderate compression degrades internal representations with little accuracy loss, revealing redundancy; all models exhibit a sharp hallucination safety cliff near 90% compression, correlated with spikes in Global Eviction Ratio (GER), suggesting a phase transition in semantic reachability; and architectures differ in routing dynamics, with LLaMA showing early consensus and late diversification, and Qwen showing funnel-like late convergence, leading to distinct resilience profiles. Beyond erasure, we identify representational rigidity, where excessive head-level consensus collapses routing flexibility despite token survival. These results suggest sparse token-route structures govern compression tolerance, reframing KV compression as a structural probe of attention geometry and linking long-context scalability to sparsity and the lottery ticket hypothesis in self-attention.

### 1. 核心问题与研究动机
*   **核心问题**：随着 LLM 上下文窗口扩展，KV 缓存成为内存瓶颈。虽然现有压缩方法声称能节省 80%-90% 空间且准确率下降极小，但作者认为这掩盖了深层结构问题：**注意力机制不仅是存储（Storage），更是路由（Routing）**。
*   **研究动机**：保留 KV 对并不意味着语义可达。作者试图探究：KV 压缩是仅仅去除了冗余，还是破坏了支撑推理的“稀疏 Token 路由”结构？他们将压缩视为对注意力几何结构的物理扰动，旨在区分信息的“保留”、“可访问性”与“利用率”。

### 2. 方法论：核心思想与关键技术
*   **物理启发框架**：将 KV 压缩建模为对 Token 级路由的受控扰动。
*   **关键指标**：
    *   **全局剔除率 (GER, Global Eviction Ratio)**：量化答案关键 Token 在所有注意力头中被全局删除的比例。GER 激增意味着语义路径被彻底切断。
    *   **层级头共识 (Head-level Consensus)**：测量不同注意力头在特定层是否关注相同的 Token。低共识意味着路由多样性，高共识意味着路由僵化。
*   **Token 路由彩票假设 (TR-LT)**：类比参数空间的彩票假设，认为注意力层中存在极少数关键的跨头、跨层路径，只要这些路径存活，推理就能保持。
*   **线性探测 (Linear Probing)**：在冻结的隐藏状态上训练分类器，检测即使生成失败时，Token 的语义特征是否仍残留在残差流中。

### 3. 实验设计
*   **数据集/场景**：设计了一套受控的合成数据集，包括：
    *   **基础任务**：实体-属性绑定。
    *   **知识操纵**：测试事实结构的系统性剔除偏见。
    *   **多实体/多存在**：测试位置鲁棒性与实例消歧。
    *   **长上下文与多跳推理 (Hops)**：测试跨越长距离的语义链条。
    *   **指代一致性 (Coreference)**：检测细粒度的路由失败与幻觉。
*   **对比模型**：LLaMA-3/3.2 (3B, 8B) 和 Qwen-2.5 (3B, 7B, 14B)。
*   **对比方法**：
    *   **压缩策略**：FINCH (分块压缩) 与 AdaKV (全局自适应头压缩)。
    *   **推理模式**：问题无关 (Question-agnostic) 与 问题感知 (Question-aware) 压缩。

*   **硬件**：实验在单张 **NVIDIA RTX A6000 GPU** 上运行。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 2 个模型家族、5 种不同参数规模（3B 到 14B）、7 大类合成任务、10% 到 90% 的压缩梯度。
*   **充分性**：实验设计非常充分。通过对比“问题感知”与“问题无关”模式，成功分离了“存储能力”与“检索策略”的影响；通过线性探测实验，验证了表示与行为之间的鸿沟。
*   **客观性**：使用了受控合成数据而非仅依赖自然语言基准，有效排除了语言冗余的干扰，使得对“路由”机制的观察更加纯粹、客观。

### 6. 主要结论与发现
*   **幻觉安全悬崖 (Safety Cliff)**：所有模型在 **90% 压缩率**附近都会出现性能骤降，这与 GER 的激增高度相关，标志着语义可达性的相变。
*   **架构路由差异**：
    *   **LLaMA**：表现为“早期共识，后期多样化”，早期层达成一致，后期层进行特征提取。
    *   **Qwen**：表现为“漏斗状”，早期探索，后期层高度收敛。
*   **两种失败模式**：
    1.  **表示擦除 (Erasure)**：关键 Token 被全局剔除，导致无法获取证据。
    2.  **表示僵化 (Rigidity)**：Token 虽然存活，但由于注意力头过度共识，导致路由缺乏灵活性，无法有效利用证据。
*   **语义层级差异**：人物（Person）和地点（Location）表示较稳健，而组织（Organization）和事件（Event）在压缩下极易崩溃。

### 7. 优点
*   **视角独特**：跳出了单纯的“准确率”评估，从“路由”和“物理动力学”角度重新审视 KV 压缩。
*   **诊断性强**：提出的 GER 和共识指标为优化压缩算法提供了明确的物理指导。
*   **揭示架构本质**：通过压缩实验反向揭示了 LLaMA 和 Qwen 在处理信息流向上的本质区别。

### 8. 不足与局限
*   **合成数据依赖**：虽然合成数据有助于机制分析，但可能无法完全模拟真实自然语言中的复杂语义重叠和修辞冗余。
*   **任务覆盖**：主要集中在检索和简单推理，对于极长文本中的创造性生成或复杂情感分析的压缩影响探讨较少。
*   **应用限制**：目前的研究更多是“诊断性”的，虽然提出了理论，但尚未直接转化成一种全新的、超越现有 SOTA 的压缩算法。
