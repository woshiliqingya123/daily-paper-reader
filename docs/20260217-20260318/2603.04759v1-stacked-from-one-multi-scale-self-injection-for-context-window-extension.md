## 摘要
当代大语言模型（LLMs）有限的上下文窗口仍然是其在不同领域广泛应用的主要瓶颈。虽然在长上下文数据上进行持续预训练提供了一种直接的解决方案，但它会产生高昂的数据获取和计算成本。为了应对这一挑战，我们提出了 SharedLLM，这是一个基于多粒度上下文压缩和查询感知信息获取的新型框架。SharedLLM 由两个堆叠的短上下文 LLM 组成：一个作为压缩器的底层模型和一个作为解码器的顶层模型。底层模型将长输入压缩为紧凑的多粒度表示，随后将其转发至顶层模型进行上下文感知处理。为了最大化效率，这种信息传递仅发生在最底层，从而绕过了冗长的前向传递和冗余的交叉注意力操作。整个过程（其中顶层和底层模型均源自相同的底层 LLM 层）被称为“自注入”（self-injection）。为了支持这种架构，一种专门的基于树的数据结构实现了上下文信息的有效编码和查询感知检索。尽管仅在 8K token 的序列上进行训练，SharedLLM 仍能有效地泛化到超过 128K token 的输入。在一系列全面的长上下文建模和理解基准测试中，SharedLLM 取得了优于或等同于强基准模型的性能，在效率和准确性之间达到了最佳平衡。此外，这些设计选择使 SharedLLM 能够显著减少内存占用，并带来显著的推理加速（比流式架构快 2 倍，比编码器-解码器架构快 3 倍）。

## Abstract
The limited context window of contemporary large language models (LLMs) remains a primary bottleneck for their broader application across diverse domains. Although continual pre-training on long-context data offers a straightforward solution, it incurs prohibitive data acquisition and computational costs. To address this challenge, we propose~\modelname, a novel framework based on multi-grained context compression and query-aware information acquisition. SharedLLM comprises two stacked short-context LLMs: a lower model serving as a compressor and an upper model acting as a decoder. The lower model compresses long inputs into compact, multi-grained representations, which are then forwarded to the upper model for context-aware processing. To maximize efficiency, this information transfer occurs exclusively at the lowest layers, bypassing lengthy forward passes and redundant cross-attention operations. This entire process, wherein the upper and lower models are derived from the same underlying LLM layers, is termed~\textit{self-injection}. To support this architecture, a specialized tree-based data structure enables the efficient encoding and query-aware retrieval of contextual information. Despite being trained on sequences of only 8K tokens, \modelname~effectively generalizes to inputs exceeding 128K tokens. Across a comprehensive suite of long-context modeling and understanding benchmarks, \modelname~achieves performance superior or comparable to strong baselines, striking an optimal balance between efficiency and accuracy. Furthermore, these design choices allow \modelname~to substantially reduce the memory footprint and yield notable inference speedups ($2\times$ over streaming and $3\times$ over encoder-decoder architectures).

*   **核心问题**：当代大语言模型（LLMs）在处理超长文本时面临“计算瓶颈”与“训练成本”的双重挑战。现有的长上下文扩展方法（如持续预训练）需要极高的算力和数据成本，而推理侧的优化（如流式处理或简单的 KV 压缩）往往会损失模型性能或导致严重的幻觉。
*   **研究动机**：作者旨在寻找一种“训练短、测试长”的高效方案。通过利用模型自身的层来构建分层架构，在不引入额外大规模参数和复杂对齐阶段的前提下，实现上下文窗口的极低成本扩展。

### 2. 方法论：SharedLLM 框架
*   **核心思想（自注入机制）**：将一个短上下文 LLM 的权重“一分为二”并堆叠。底层模型（Lower Model）取原模型的前 $M$ 层作为压缩器；顶层模型（Upper Model）作为解码器。由于两者源自同一模型，隐藏空间天然对齐，无需复杂的预热训练。
*   **关键技术细节**：
    *   **上下文树（Context Tree）**：将长文本划分为多个块（Chunks），为每个块构建二叉树。树的高层存储粗粒度信息（高压缩比），底层存储细粒度信息（低压缩比）。
    *   **查询感知动态构建与搜索**：在推理时，根据当前 Query 与文本块的语义相似度（余弦相似度），动态决定展开树的哪些分支。相关的部分保留细粒度 KV 状态，不相关的部分仅保留粗粒度摘要。
    *   **位置感知交叉注意力**：在顶层模型的前 $M$ 层插入交叉注意力模块，通过块级旋转位置编码（RoPE）确保模型能够识别压缩块之间的全局先后顺序。
    *   **多粒度压缩**：通过分级下采样（Fractional Strided Selection）减少 KV 缓存量，理论复杂度从 $O(T^2)$ 降至接近线性。

### 6. 主要结论与发现
*   **外推能力极强**：SharedLLM 仅需在 8K 长度上训练，即可在 128K 长度下保持极低的困惑度，且不发生性能崩溃。
*   **性能领先**：在 LongBench 和 InfiniBench 上，SharedLLM 的得分普遍高于 Activation Beacon 和 CEPE 等强基线。
*   **效率优势显著**：相比于 CEPE（编码器-解码器架构），推理速度提升了 **3 倍**；相比于流式架构，速度提升了 **2 倍**。
*   **内存节省**：通过树状压缩，内存占用远低于传统的全注意力模型，且能兼容 FlashAttention 等高性能算子。

### 7. 优点：亮点总结
*   **自注入架构的优雅性**：巧妙利用预训练模型自身的层级结构，解决了异构模型（如 BERT+LLM）组合时难以对齐和训练收敛慢的问题。
*   **动态平衡**：上下文树结构允许模型在“全局概览”和“局部细节”之间通过 Query 驱动进行动态平衡，这比静态的下采样更符合人类阅读长文本的逻辑。
*   **极高的资源效率**：在有限的算力（8 张 A800）和极短的训练长度（8K）下实现了超长上下文（128K+）的处理。

### 8. 不足与局限
*   **Query 依赖性**：在没有明确 Query 的纯文本生成或续写任务中，动态搜索策略退化为固定分支选择（如 Λ-shape），性能提升可能不如 QA 类任务显著。
*   **超参数敏感性**：实验显示树的高度（Tree Height）和压缩比（Compression Ratio）对结果有显著影响，不同任务可能需要不同的配置，缺乏一种完全自适应的机制。
*   **首字延迟（TTFT）**：虽然整体推理速度快，但构建上下文树和进行查询感知搜索会引入额外的前向传递开销，可能增加首字生成的延迟。
