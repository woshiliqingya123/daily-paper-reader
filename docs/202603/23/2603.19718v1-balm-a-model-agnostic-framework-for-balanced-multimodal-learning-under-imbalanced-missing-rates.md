## 摘要
从多个模态中学习通常会面临不平衡问题，即信息丰富的模态主导优化过程，而较弱或部分缺失的模态贡献较少。在具有不平衡缺失率（IMR）的现实场景中，这种不平衡变得更加严重，其中每个模态以不同的概率缺失，从而扭曲了表示学习和梯度动力学。我们从训练过程的角度重新审视这一问题，并提出了 BALM，这是一种模型无关的插件式框架，旨在实现 IMR 下的平衡多模态学习。该框架包含两个互补模块：特征校准模块（FCM），利用全局上下文重新校准单模态特征，以在异构缺失模式之间建立共享的表示基础；梯度重平衡模块（GRM），通过从分布和空间两个维度调节梯度的幅度和方向，来平衡各模态之间的学习动力学。BALM 可以无缝集成到包括多模态情感识别（MER）模型在内的各种骨干网络中，而无需改变其架构。在多个 MER 基准测试上的实验结果证实，BALM 在各种缺失和不平衡设置下都能持续增强鲁棒性并提升性能。代码可在以下地址获取：https://github.com/np4s/BALM_CVPR2026.git

## Abstract
Learning from multiple modalities often suffers from imbalance, where information-rich modalities dominate optimization while weaker or partially missing modalities contribute less. This imbalance becomes severe in realistic settings with imbalanced missing rates (IMR), where each modality is absent with different probabilities, distorting representation learning and gradient dynamics. We revisit this issue from a training-process perspective and propose BALM, a model-agnostic plug-in framework to achieve balanced multimodal learning under IMR. The framework comprises two complementary modules: the Feature Calibration Module (FCM), which recalibrates unimodal features using global context to establish a shared representation basis across heterogeneous missing patterns; the Gradient Rebalancing Module (GRM), which balances learning dynamics across modalities by modulating gradient magnitudes and directions from both distributional and spatial perspectives. BALM can be seamlessly integrated into diverse backbones, including multimodal emotion recognition (MER) models, without altering their architectures. Experimental results across multiple MER benchmarks confirm that BALM consistently enhances robustness and improves performance under diverse missing and imbalance settings. *   **核心问题**：在现实应用中，不同传感器或数据源的可靠性不同，导致各模态的缺失概率并不相等（即 **不平衡缺失率 IMR**）。
*   **研究背景**：
    *   **表示失衡**：不同模态的缺失模式会扭曲特征分布，阻碍一致的跨模态融合。
    *   **优化失衡**：缺失率低的模态在训练中占据主导，导致梯度被频繁出现的模态支配，而缺失率高的模态则面临严重的欠拟合。
*   **局限性**：现有研究大多假设所有模态具有相同的缺失率（SMR），这在实际中过于理想化，导致模型在面对异构缺失模式时性能不稳定。

### 2. 方法论：BALM 框架
BALM 是一个**模型无关（Model-Agnostic）**的插件式框架，包含两个核心模块：

*   **特征校准模块 (FCM - Feature Calibration Module)**：
    *   **核心思想**：利用全局上下文信息来校准受损的单模态特征。
    *   **技术细节**：通过平均池化获取各模态的全局描述符，连接后通过全连接层提取跨模态上下文，生成模态特定的校准权重（类似 Squeeze-and-Excitation 机制），对原始特征进行门控缩放，从而在特征层面建立统一的表示基础。
*   **梯度重平衡模块 (GRM - Gradient Rebalancing Module)**：
    *   **分布驱动调节**：引入辅助单模态预测头，计算单模态预测与多模态预测之间的 **KL 散度**。根据散度的变化率动态调整各模态编码器的梯度步长（$\mu_m$），学习慢的模态获得更大的梯度增益。
    *   **空间驱动调节**：计算单模态梯度与全局梯度之间的**余弦相似度**，通过正则化项强制各模态的优化方向向平衡的多模态目标对齐，防止模型被单一主导模态带偏。

### 7. 优点与亮点
*   **模型无关性**：作为插件使用，不需要修改原有的复杂融合架构（如 Transformer 或 Graph 结构），易于迁移。
*   **双重平衡机制**：同时从**特征表示**（FCM）和**梯度优化**（GRM）两个维度解决不平衡问题，比单一的重采样或损失加权更全面。
*   **动态调节**：GRM 模块不依赖先验的缺失率统计，而是根据训练过程中的实时学习进度（KL 散度变化）动态调整，具有自适应性。

### 8. 不足与局限
*   **计算开销**：虽然模块轻量，但引入了辅助预测头和梯度相似度计算，在超大规模模型上可能会增加一定的显存占用和训练耗时。
*   **任务覆盖**：实验主要集中在多模态情感识别（MER）任务上，虽然具有代表性，但在多模态检索、视觉问答（VQA）等其他领域的泛化能力尚待进一步验证。
*   **极端情况**：当所有模态缺失率都极高（如全部 > 0.8）时，全局上下文的可靠性会下降，FCM 的校准效果可能会受限。
