## 摘要
自一致性通过并行采样多个推理路径并进行投票，提升了推理阶段的性能。然而，在数学和代码等受限领域，这种策略的计算效率较低，因为它采用有放回采样，会重复访问相同的高概率前缀并生成重复的补全结果。我们提出了唯一叶节点枚举（Distinct Leaf Enumeration, DLE），这是一种确定性解码方法，它将截断采样视为对剪枝解码树的遍历，并系统地枚举唯一的叶节点，而非进行有放回采样。该策略从两个方面提高了推理效率：在算法层面，它通过探索此前未访问的高概率分支，在固定预算下增加了截断搜索空间的覆盖范围；在系统层面，它复用了共享前缀并减少了冗余的 Token 生成。实验表明，相比于随机自一致性，DLE 能够探索更高质量的推理路径，在数学、编程和通用推理任务上均取得了更好的性能。

## Abstract
Self-consistency boosts inference-time performance by sampling multiple reasoning traces in parallel and voting. However, in constrained domains like math and code, this strategy is compute-inefficient because it samples with replacement, repeatedly revisiting the same high-probability prefixes and duplicate completions. We propose Distinct Leaf Enumeration (DLE), a deterministic decoding method that treats truncated sampling as traversal of a pruned decoding tree and systematically enumerates distinct leaves instead of sampling with replacement. This strategy improves inference efficiency in two ways. Algorithmically, it increases coverage of the truncated search space under a fixed budget by exploring previously unvisited high-probability branches. Systemically, it reuses shared prefixes and reduces redundant token generation. Empirically, DLE explores higher-quality reasoning traces than stochastic self-consistency, yielding better performance on math, coding, and general reasoning tasks.

### 1. 核心问题与整体含义（研究动机和背景）
*   **研究动机**：目前提升模型推理能力的常用方法是“自一致性采样”，即并行采样多个推理路径并投票。但在数学、代码等受限领域，这种随机采样（有放回采样）非常低效，会产生大量重复的前缀和完全相同的解，浪费了宝贵的推理算力。
*   **核心问题**：如何在固定的 Token 预算下，更系统地探索模型的推理空间，避免重复计算，从而提高推理性能和效率？
*   **整体含义**：论文将解码过程视为对“截断解码树”的遍历，通过确定性地枚举不同的叶节点（推理路径）来替代随机采样，从而在算法和系统两个层面实现优化。

### 2. 方法论：核心思想与技术细节
*   **核心思想**：DLE 不再从概率分布中随机抽样，而是根据截断规则（如 top-p, min-p, $\epsilon$-sampling）确定的候选 Token 集合，系统地、确定性地探索解码树中概率最高的、互不重复的路径。
*   **关键技术细节**：
    *   **截断分布（Truncated Distribution）**：利用 $\epsilon$-sampling 等规则过滤掉低概率的噪声 Token，缩小搜索树的规模。
    *   **确定性枚举流程**：
        1.  首先进行一次贪婪搜索（Greedy Generation）。
        2.  记录路径上所有存在多个候选 Token 的分支点。
        3.  **分支选择策略（Prob-First）**：优先选择路径概率质量（Path Probability Mass）最大的未访问分支进行探索。
        4.  **贪婪补全**：从分支点开始，后续 Token 全部采用贪婪生成，直到结束。
    *   **早停机制（Early Stopping）**：如果新分支生成的 Token 序列与已有路径在 $n$ 个 Token 内发生重合（Merge），则立即停止该分支，避免生成重复的后缀。
    *   **前缀复用**：由于是树状探索，DLE 可以天然地复用 KV Cache，减少重复前缀的计算开销。

### 6. 主要结论与发现
*   **性能提升**：在相同序列数量下，DLE 在 GSM8K 上比随机采样提升了约 3-9%，在 HumanEval 上提升了 4-7%。
*   **覆盖率与准确率正相关**：DLE 能够比随机采样覆盖更多的概率质量（Probability Mass），这是其性能更强的根本原因。
*   **极高的 Token 效率**：DLE 达到与随机采样相同的准确率时，所需的 Token 数量大幅减少（例如在某些配置下仅需其 1/10 的新 Token）。
*   **系统加速**：结合 SGLang 等引擎，DLE 的实际推理延迟显著低于随机采样，尤其是在显存受限或小 Batch Size 场景下。

### 7. 优点（亮点）
*   **算法简洁且通用**：DLE 是一个即插即用的解码替代方案，适用于 top-p、min-p 等多种主流采样规则。
*   **理论与实践结合**：不仅在算法层面通过“覆盖率”解释了有效性，还在系统层面通过 KV Cache 复用证明了实用性。
*   **解决重复性痛点**：针对 LLM 在受限领域容易陷入重复路径的顽疾，给出了优雅的确定性解决方案。

### 8. 不足与局限
*   **领域局限性**：该方法在数学和代码等“答案空间相对受限”的领域效果最好。对于开放式创意写作等需要极高多样性的任务，确定性枚举可能会降低生成结果的丰富度。
*   **依赖截断规则**：DLE 的效果高度依赖于预设的截断阈值（如 $\epsilon$ 或 $p$）。如果阈值设置不当，可能会漏掉正确的低概率路径或包含过多噪声。
*   **早停启发式**：早停机制基于 $n$-gram 匹配，虽然有效但仍属于启发式方法，可能存在误伤潜在正确路径的风险。
