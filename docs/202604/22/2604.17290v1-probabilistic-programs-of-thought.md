## 摘要
大语言模型（LLMs）被广泛用于代码生成和数学推理任务，在这些任务中，它们需要生成结构化输出。它们通常需要对代码进行推理、根据给定规范生成代码，或使用思维程序（programs of thought）进行推理。代码生成的典型方法是提示模型并生成样本，直到获得合适的程序。在此过程中，从语言模型中采样 $n$ 个程序需要进行 $n$ 次 GPU 计算密集型生成，当 $n$ 较大时，其成本变得极其昂贵。在这项工作中，我们通过在生成的程序本身中暴露 LLM 的分布来解决这一局限性。我们提出了一种名为“概率思维程序”（probabilistic programs of thought）的新型测试时框架，旨在通过更少的 LLM 生成次数从模型中获取更多样本。给定模型生成的程序及其相关的下一标记（next-token）概率，我们构建了一个概率程序，该程序紧凑地表示了指数级数量的确定性程序。由于在该概率程序中进行概率推理的成本要低得多，我们的方法允许在不增加任何 GPU 计算且仅需极少 CPU 开销的情况下采样新程序。我们在代码生成、代码理解和数学推理的基准测试上实例化了我们的方法，并报告了在减少 LLM 生成次数的情况下性能的提升。

## Abstract
LLMs are widely used for code generation and mathematical reasoning tasks where they are required to generate structured output. They either need to reason about code, generate code for a given specification, or reason using programs of thought. The typical approach to code generation is to prompt the model and generate samples until an appropriate program is obtained. Within this process, sampling $n$ programs from the language model requires $n$ GPU compute-intensive generations which becomes prohibitively expensive for larger values of $n$. In this work, we address this limitation by exposing the LLM's distribution within the generated programs themselves. We propose a novel test-time framework we dub probabilistic programs of thought to obtain more samples from the model with fewer LLM generations. Given a program generated by a model and the associated next-token probabilities, we build a probabilistic program that compactly represents exponentially many deterministic programs. Since performing probabilistic reasoning in this probabilistic program is much cheaper, our approach allows sampling new programs without any additional GPU compute and little CPU overhead. We instantiate our approach on benchmarks for code generation, code understanding and mathematical reasoning and report improvements in performance with fewer generations from the LLM.

*   **核心问题**：大语言模型（LLM）在处理代码生成、数学推理等任务时，通常采用“采样-执行-验证”（Best-of-n）策略。然而，每获取一个新样本都需要进行一次完整的 GPU 密集型前向计算。当采样数量 $n$ 较大时，计算成本和延迟变得不可接受。
*   **研究动机**：作者观察到，LLM 在生成代码时，其输出层（Logits）其实已经包含了丰富的概率分布信息。如果能直接利用这些分布信息在“程序空间”内进行局部调整，而不是重新从头生成，就能以极低的代价获得大量高质量的候选样本。

### 2. 方法论
*   **核心思想**：将 LLM 生成的确定性代码视为一个“概率程序”的草案。通过将代码中不确定的关键标记（如数字、算术运算符、比较符）转化为随机变量，构建一个**概率思维程序（PPoT）**。
*   **关键技术细节**：
    *   **概率程序构建**：给定 LLM 生成的一个程序，识别其中的特定标记（Token）。利用该位置的下一标记概率分布（Next-token probabilities），将这些标记定义为分类随机变量（Categorical RVs）。
    *   **可处理性编译**：为了保证计算效率，目前主要针对单标记（Single-token）组件进行替换（如将 `+` 替换为 `{- , * , /}` 等），避免了处理多标记组件时复杂的计算问题。
    *   **条件采样**：使用一种“不放回采样”策略，确保从概率程序中抽取的 $m$ 个新样本不与原始 LLM 样本重复，从而增加多样性。
    *   **算法流程**：
        1.  LLM 生成一个初始程序并保留 Logits。
        2.  分析程序，识别数字、运算符等关键位置。
        3.  在 CPU 上根据 Logits 分布对这些位置进行重采样，生成 $m$ 个变体程序。
        4.  执行所有程序并通过验证器（Verifier）筛选正确答案。

*   **实验规模**：涵盖了从 0.5B 到 7B 不同规模的模型，并在三个完全不同的任务领域（数学、绘图、逻辑推理）进行了验证。

### 6. 主要结论与发现
*   **性能提升**：在不增加 GPU 开销的情况下，PPoT 使 Qwen2.5 在各基准测试上的准确率提升了 **2% 到 7%**。

### 7. 优点
*   **极低成本**：利用了 LLM 已有的 Logits 信息，将昂贵的 GPU 生成转化为廉价的 CPU 采样。
*   **即插即用**：作为一种测试时（Test-time）技术，不需要对模型进行微调，可直接应用于现有的代码生成模型。
*   **理论完备**：论文提供了算法的分布完备性（Soundness）证明，确保采样过程在独立性假设下符合模型原始分布。

*   **独立性假设**：算法假设重采样的标记与后续标记相互独立，这在处理长程依赖或复杂的逻辑结构时可能不成立。
