## 摘要
人类的认知发展不仅受个人努力的影响，还受到结构化社会交互的塑造。在这种交互中，基于角色的交流（如导师与学习者之间的交流）能够产生双方单独都无法实现的解决方案。受这些发展原则的启发，我们探讨了导师-学生多智能体系统是否能产生协同效应，从而推动大语言模型（LLM）超越其在现有框架下的能力。为了验证这一想法，我们采用了自动编程问题领域，其中两个由同一 LLM 实例化的智能体被分配了不对称的角色：学生智能体负责生成并迭代优化解决方案，而导师智能体在无法获取标准答案的情况下提供结构化的评估反馈。在我们提出的框架（PETITE）中，我们的目标是通过互补角色构建交互结构，从单一模型中挖掘出更好的问题解决性能，而不是依赖更强的监督模型或异构集成。我们在 APPS 编程基准测试上对模型进行了评估，并与 Self-Consistency、Self-Refine、Multi-Agent Debate 和 Multi-Agent Review 等前沿方法进行了对比。结果表明，我们的模型在消耗显著更少 Token 的情况下，实现了相似或更高的准确率。这些结果表明，基于发展理论的角色差异化交互结构，为通过结构化的类同伴交互增强 LLM 问题解决能力提供了一种有原则且资源高效的范式。

## Abstract
Human cognitive development is shaped not only by individual effort but by structured social interaction, where role-based exchanges such as those between a tutor and a learner, enable solutions that neither could achieve alone. Inspired by these developmental principles, we ask the question whether a tutor-student multi-agent system can create a synergistic effect by pushing Large Language Model (LLM) beyond what it can do within existing frameworks. To test the idea, we adopt autonomous coding problem domain where two agents instantiated from the same LLM assigned asymmetric roles: a student agent generates and iteratively refines solutions, while a tutor agent provides structured evaluative feedback without access to ground-truth answers. In our proposed framework (PETITE), we aim to extract better problem-solving performance from one model by structuring its interaction through complementary roles, rather than relying on stronger supervisory models or heterogeneous ensembles. Our model is evaluated on the APPS coding benchmark against state-of-the-art approaches of Self-Consistency, Self-Refine, Multi-Agent Debate, and Multi-Agent Review. The results show that our model achieves similar or higher accuracy while consuming significantly fewer tokens. These results suggest that developmentally grounded role-differentiated interaction structures provide a principled and resource-efficient paradigm for enhancing LLM problem-solving through structured peer-like interactions. *   **研究动机**：人类认知发展通常发生在社会交互中，特别是“导师”与“学生”的角色分工能产生 1+1>2 的协同效应。
*   **核心问题**：现有的 LLM 提升策略（如自我修正或多智能体辩论）往往消耗大量 Token 且效果不稳定。作者探讨是否可以通过在单一模型中设定“非对称角色”（生成者 vs 评估者），在不依赖更强模型或外部监督的情况下，突破模型独立解题的上限。
*   **背景**：借鉴了维果茨基的“最近发展区”（ZPD）理论和脚手架（Scaffolding）教学法。

### 2. 方法论
*   **核心思想**：将同一个 LLM 实例化为两个具有不同系统提示词（System Prompt）的智能体：**学生（Coder）**和**导师（Tutor）**。
*   **关键技术细节**：
    *   **学生代理**：负责根据问题描述编写代码，并根据导师反馈进行迭代优化。
    *   **导师代理**：负责评估代码的逻辑、语法、边界情况等，提供结构化反馈，但**不接触标准答案**。
    *   **早停机制（Early Stopping）**：导师在反馈末尾给出“Decision: Correct”或“Decision: Wrong”。一旦导师判定正确，流程立即终止。
*   **算法流程**：
    1. 初始化学生和导师的对话上下文。
    2. 学生生成初始方案。
    3. 导师评估方案并给出反馈。
    4. 若导师判定正确或达到最大迭代次数，则输出结果；否则，学生根据反馈更新代码，循环往复。

### 3. 实验设计
*   **数据集**：从 **APPS** 编程基准测试中随机抽取 100 个题目，涵盖入门（Introductory）、面试（Interview）和竞赛（Competition）三个难度等级。
*   **对比方法（Baselines）**：
    *   **Self-Consistency (SC)**：采样 5 次和 10 次。
    *   **Self-Refine (SR)**：单模型自我修正（1-2 次迭代）。
    *   **Multi-Agent Debate (MAD)**：多智能体辩论（最多 10 轮）。
    *   **MARS**：包含评审员和元评审员的多智能体评审系统。
*   **评估指标**：成功率（Success Rate）、改进幅度（Improvement）、Token 消耗量、效率比（成功率/Token 消耗）。

### 4. 资源与算力
*   **硬件**：使用单张 **NVIDIA RTX 4060 (8GB VRAM)** 显卡。
*   **模型配置**：基础模型为 **Qwen2.5-Coder-7B-Instruct**，采用 **4-bit 量化 (NF4)** 以实现高效推理。
*   **参数设置**：最大上下文 4096 Token，生成上限 2048 Token，采样温度 0.7-0.8。

### 5. 实验数量与充分性
*   **实验规模**：针对 100 个具有代表性的编程问题进行了多轮测试。
*   **充分性分析**：
    *   实验对比了 PETITE 在不同迭代次数（1, 2, 3 次）下的表现。
    *   针对不同难度等级进行了细分分析。
    *   对比了当前主流的多种单智能体和多智能体框架。
    *   **评价**：实验设计较为客观，通过控制变量（使用相同的基座模型）确保了公平性，但 100 个样本的规模在统计严密性上略显单薄。

### 6. 主要结论与发现
*   **性能优越**：PETITE（2 次迭代）达到了最高的综合成功率（31.62%），优于所有基准方法。
*   **Token 效率极高**：在面试难度题目上，PETITE 比 MAD 节省了约 **81%** 的 Token，比 Self-Refine 节省了 **67%**。
*   **非对称性优势**：证明了将“生成”与“评估”职责分离，比让模型同时承担两种职责（Self-Refine）或对称辩论（MAD）更有效。
*   **早停机制有效**：自适应的计算资源分配（简单题少迭代，难题多迭代）显著降低了冗余开销。

### 7. 优点
*   **理论支撑扎实**：将成熟的发展心理学理论成功引入 LLM 多智能体设计。
*   **资源友好**：极低的 Token 消耗使其非常适合在端侧设备或预算有限的场景下部署。
*   **无需外部监督**：导师代理在没有标准答案的情况下依然能提供高质量的纠错指导。

### 8. 不足与局限
*   **导师可靠性风险**：如果导师代理产生幻觉或误判（将错判对），会导致过早停止，从而降低准确率。
*   **样本覆盖面**：实验仅在 100 个 APPS 题目上进行，且仅限于编程领域，其在数学推理或通用写作等领域的泛化能力尚待验证。
*   **同质化限制**：学生和导师使用相同的基座模型，可能存在视角单一的问题；未来若引入异构模型（如更强的模型当导师）可能会有更大提升。
