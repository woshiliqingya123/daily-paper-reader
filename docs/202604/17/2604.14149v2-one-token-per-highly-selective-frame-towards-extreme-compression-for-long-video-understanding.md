## 摘要
长视频理解对视觉语言模型（VLM）而言具有内在挑战性，因为其帧数庞大。由于每个视频帧通常会扩展为数十或数百个 token，大语言模型（LLM）有限的上下文长度迫使 VLM 只能稀疏地感知帧，从而丢失时间信息。为解决这一问题，我们探索了极端的视频 token 压缩，旨在 LLM 的最后一层实现每帧仅一个 token。我们的核心见解是，先前方法广泛采用的基于启发式的压缩容易导致信息丢失，因此有必要将 LLM 层监督为可学习且渐进式的 token 级压缩模块（LP-Comp）。这种压缩使我们的 VLM 能够处理 2 到 4 倍的帧数，并提升性能。为了进一步提高 token 效率，我们研究了帧级压缩，即通过 LLM 层的内部注意力分数选择与查询最相关的帧，称之为问题条件压缩（QC-Comp）。与以往研究的一个显著区别是，我们通过将长视频分割成短片段并采用局部注意力，缓解了长上下文中 LLM 注意力的位置偏差（即过度集中在序列的开头和结尾）。总之，我们将 token 级和帧级压缩相结合，构建了一个名为 XComp 的长视频理解极端压缩模型，实现了显著更高的压缩率并支持更密集的帧采样。我们的 XComp 基于 VideoChat-Flash 进行微调，采用了一个数据高效的监督压缩微调阶段，仅需 2.5% 的监督微调数据，却将 LVBench 上的准确率从 42.9% 提升至 46.2%，并增强了多个其他长视频基准测试的表现。

## Abstract
Long video understanding is inherently challenging for vision-language models (VLMs) because of the extensive number of frames. With each video frame typically expanding into tens or hundreds of tokens, the limited context length of large language models (LLMs) forces the VLMs to perceive the frames sparsely and lose temporal information. To address this, we explore extreme video token compression towards one token per frame at the final LLM layer. Our key insight is that heuristic-based compression, widely adopted by previous methods, is prone to information loss, and this necessitates supervising LLM layers into learnable and progressive modules for token-level compression (LP-Comp). Such compression enables our VLM to digest 2x-4x more frames with improved performance. To further increase the token efficiency, we investigate frame-level compression, which selects the frames most relevant to the queries via the internal attention scores of the LLM layers, named question-conditioned compression (QC-Comp). As a notable distinction from previous studies, we mitigate the position bias of LLM attention in long contexts, i.e., the over-concentration on the beginning and end of a sequence, by splitting long videos into short segments and employing local attention. Collectively, our combined token-level and frame-level leads to an extreme compression model for long video understanding, named XComp, achieving a significantly larger compression ratio and enabling denser frame sampling. Our XComp is finetuned from VideoChat-Flash with a data-efficient supervised compression tuning stage that only requires 2.5% of the supervised fine-tuning data, yet boosts the accuracy from 42.9% to 46.2% on LVBench and enhances multiple other long video benchmarks.

### 论文总结：One Token per Highly Selective Frame (XComp)

#### 1. 核心问题与整体含义
长视频理解的主要瓶颈在于**视觉 Token 爆炸**。现有的视觉语言模型（VLM）在处理长视频时，每帧通常被编码为数十甚至数百个 Token，这迅速耗尽了大语言模型（LLM）的上下文窗口。为了应对这一挑战，现有方法多采用启发式的稀疏采样或简单的池化压缩，但这往往会导致关键时空信息的丢失。

本文的研究动机在于探索**极端压缩（Extreme Compression）**的可能性：即在 LLM 的最终输出层，将每一帧的信息浓缩为**仅一个 Token**，同时通过可学习的机制和问题引导的选择性机制，确保这一个 Token 包含最高效的信息。

---

#### 2. 方法论
XComp 框架结合了 Token 级和帧级两个维度的压缩策略：

*   **LP-Comp（可学习且渐进式的 Token 压缩）**：
    *   **核心思想**：不再依赖预定义的启发式规则，而是通过监督微调让 LLM 层学会如何将多 Token 浓缩。
    *   **渐进式调度**：采用**余弦调度（Cosine Schedule）**，在 LLM 的 $L$ 层结构中平滑地减少每帧的 Token 数，避免信息在单层内骤减。
    *   **后缀保留（Suffix-Preservation）**：利用 Decoder-only LLM 的因果注意力特性，规定压缩时保留每帧最后的 Token，因为后续 Token 能够通过注意力机制吸收前面 Token 的特征。
*   **QC-Comp（问题引导的帧级压缩）**：
    *   **核心思想**：在推理阶段，根据用户问题动态筛选最相关的视频帧。
    *   **分段局部注意力（Segmented Local Attention）**：针对 LLM 在长序列中存在的“位置偏差”（容易关注开头和结尾，即 Lost in the Middle 问题），将长视频切分为短片段，在片段内计算问题与视频帧的注意力分数，从而更客观地评估每帧的相关性。

#### 6. 主要结论与发现
*   **极端压缩可行性**：LLM 层具备强大的信息浓缩能力，通过微调可以实现“每帧一 Token”的极端目标而不损失核心语义。
*   **性能随帧数增长**：与许多模型在增加帧数后性能下降不同，XComp 展现出随输入帧数增加（从 128 增至 1024+）性能持续提升的趋势。
*   **局部注意力的重要性**：在长视频中，全局注意力分数受位置偏差干扰严重，局部片段评分能更精准地定位关键帧。

#### 7. 优点
*   **极高的数据效率**：仅需 2.5% 的数据即可完成压缩能力的迁移，显著降低了训练成本。
*   **计算与存储双赢**：大幅减少了 KV Cache 的占用和计算开销，使 2B 规模的模型能处理数千帧的密集采样。
*   **设计优雅**：LP-Comp 和 QC-Comp 分别从模型内部表征和外部推理逻辑解决了 Token 冗余问题，且互补性强。

#### 8. 不足与局限
*   **细粒度任务损失**：在 VideoOCR（视频文字识别）等需要极高空间分辨率的任务中，由于 Token 压缩过于剧烈，性能较基线有轻微下降。
*   **模型规模限制**：实验主要集中在 2B 规模的模型上，虽然证明了潜力，但在更大规模（如 70B+）模型上的表现和压缩极限尚待验证。
*   **联合优化空间**：目前帧级选择（QC-Comp）主要在推理侧，若能在训练阶段实现问题引导的动态压缩，可能进一步提升上限。
